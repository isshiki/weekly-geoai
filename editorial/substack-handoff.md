# Substack掲載手順（ニュース中心・画像付き）

2026年10月16日号から適用。対象ニュースは前週金曜〜木曜（初回は10月9〜15日）。過去のサンプル期間とは異なる。予約時刻は既存設定を確認して引き継ぎ、この準備だけでは配信・予約操作を行わない。

## 原稿の準備

1. 木曜に注目3件・短報3〜5件・任意の地図0〜1件と、所感の切り口を提案する。
2. 選定後、`scripts/build_weekly.py`で下書きを作る。`editorial_format: news-v1`を保持し、候補を選別して`## 短報`と必要なら`## 今週の地図`を挿入する。生成時点の注目枠に全候補を残さない。
3. 注目記事は2〜6文、短報・地図は1〜2文。見出しは従来どおり `### 1. [見出し](<https://...>)`。強調は `**文字**` を使える。
4. 所感2段落は本人のコメントを基に作る。未記入ならプレースホルダを残す。試作の編集用導入文を本人の所感へ転用しない。
5. 図版は0〜2枚。`drafts/assets/YYYY-MM-DD/`にPNG・JPEG・WebPを保存し、代替テキストとキャプションを付ける。出典と利用条件は `editorial/` のその号の編集メモへ記録する。

## 確認済み原稿のHTML化

原稿レビュー後、HTML作成の依頼を受けて実行する。

```powershell
python scripts/publish_issue.py drafts/2026-10-16.md
```

このコマンドはローカルHTMLを生成するだけで、配信はしない。画像は `substack/assets/YYYY-MM-DD/` に複製され、HTMLから相対参照される。HTMLと画像フォルダーは一緒に保管する。タイトル・サブタイトルは別欄に入力する。

## Substackへの貼り付け

1. `substack/YYYY-MM-DD.html`を**ブラウザーで表示**する。HTMLソースやMarkdownをそのまま貼らない。
2. 記事タイトルをSubstackのタイトル欄、メタデータのsubtitleをサブタイトル欄へ入れる。
3. ブラウザーに表示した内容のうち、タイトルを除く本文をコピーして本文欄に貼る。HTMLコメントは生成時に除去される。
4. ローカル画像のコピーは配信先で表示できることを保証しない。コピーされた画像があれば差し替え、対応するPNG等をSubstackの画像挿入操作で**個別にアップロード**する。キャプションは貼り付け後に重複なく添える。
5. 独自CSS・カード配置・背景色の再現に依存せず、Substackの見出し・段落・画像の標準表示に合わせる。試作用HTMLのデザインをそのまま配信用に使わない。

## 配信前の目視確認

- タイトルが本文に重複していない。サブタイトルは具体的なニュースになっている。
- 見出し、通し番号、段落、リンク、強調が崩れていない。
- 画像2枚以内。挿入位置、代替テキスト、キャプション、出典を確認する。
- Substack上のプレビューで、スマートフォン幅でも画像内文字が読める。読めなければ図を簡略化・削除する。
- テストメールで本文・画像・リンクを確認する。ブラウザーの表示確認だけをメールでの検証済みとしない。
- 号数・対象期間・配信日時・タイムゾーン・宛先設定を確認してから、本人が予約するか、明示された配信依頼に従う。

この手順は運用準備であり、現時点でSubstackへの貼り付けやテストメール送信を検証したものではない。
