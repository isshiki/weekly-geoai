# Atlasの不足・重複点検と次の整備

点検日：2026-10-06。対象は現行Atlasの基礎・学習導線と、前回の調査比較から整理した論点である。調査ファイル9本は元のDownloadsパスに存在せず、今回の原文再照合は未了。各AIの回答数や一致率を再集計したものではない。追加解説は公式資料で確認した。

## 対応表

| 論点 | 現状・不足 | 判断と対応 |
| --- | --- | --- |
| 全体像・CRS・予測と説明・検証 | 基礎5テーマと演習がある | 新設を重ねず既存ページを入口とする |
| ベクター／ラスター | 空間結合に短い定義はあるが、学習入口がない | 表現・解像度・値の区別を1ページ新設 |
| 空間索引 | 索引レビューの紹介中心。候補と厳密判定の違いが薄い | 既存ページにSTRtreeの具体例と選択条件を追加 |
| 解像度・集計単位 | 地形の測定距離と、空間結合のMAUPに分散 | 新ページの解像度説明から両ページへ接続。総合ページの新設は保留 |
| 来歴 | Overtureのレコードメタデータ中心 | 既存ページへ入力・処理・出力の対応と記録例を追加 |
| CNGと各形式 | 概要・図があり、記事単位の追記も多い | 次回、保存・検索・配信の役割と読む順を再編集 |
| 画像解析・埋め込み・GISエージェント | 個別手法のページはある | CNG整理後、入力・出力・評価の共通軸で接続する |
| 実行演習 | 架空店舗の空間結合を実行済み | 既存演習を入口として維持。新しい演習の大量追加はしない |

## 重複の扱い

- CRSの詳細はcoordinate-reference-systems、境界判定はspatial-join-and-aggregation、評価はspatial-analysis-validationを正本とする。案内ページは概要とリンクを中心にする。
- 解像度、位置精度、集計単位、測定距離は関連するが同義ではない。単一の「スケール」の説明へ混ぜない。
- CNGの概念説明と形式別の仕様説明は役割を分ける。公開済みURLは維持する。

## 残る確認事項

- 元の調査ファイル9本との逐条照合。現状ではモデル別の網羅性や誤り数を評価しない。
- 空間索引レビューの全文。従来の403・抄録のみ確認という範囲を維持し、追加の公式仕様で代用して全文確認済みとはしない。
- CNGのRange RequestとCORSの適用条件。ブラウザーとサーバー側処理の違いを含め、次回一次資料で再点検する。
- 今回の基礎追記では製品料金・全外部リンク・実データの演習を再検証していない。元の出典確認日を保持する。

## 次回の具体的な範囲

1. CNGと、GeoParquet・COG・PMTiles・STACの既存説明を棚卸しする。
2. 「保存する／見つける／分析する／地図へ配信する」の表と、代表的な構成図を整える。
3. 部分取得が働く条件を、ファイル構造・配信側・読むツールに分ける。形式だけで高速化を保証しない。
4. 基礎・POI・画像解析から読む導線と履歴を更新し、検証後にコミット・公開する。

その次に、GeoAI手法を入力・出力・検証方法で整理する。今回の棚卸しは全ページの事実監査完了を意味しない。
