# GeoAIアトラスについて

GeoAIアトラスは、地図・位置情報データとAIに関する知見を、長く参照できる形で体系的に整理するための日本語サイトです。

技術、データ、ツール、活用事例などをテーマ別にまとめていきます。

本サイトでは、地図・位置情報・POIなどの地理空間データを、機械学習やデータサイエンスの手法で分析・活用する領域をGeoAIと呼びます。

## 週刊GeoAIについて

GIS・位置情報の仕事をしていて、AI・機械学習側の動きを短時間で追いたい人のための日本語ニュースレターです。1週間分のニュース・論文・事例を、毎週金曜にまとめてSubstackで配信します。

週刊GeoAIのバックナンバーは[Substackのアーカイブ](https://weeklygeoai.substack.com/archive)で公開します。GeoAIアトラスには同じ本文を複製せず、ニュースや論文から得た知見をテーマ別に整理します。
