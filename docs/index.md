# GeoAIアトラス

地図・位置情報データ×AIの知見を、長く参照できる形で体系的に整理するサイトです。

技術、データ、ツール、活用事例などをテーマ別にまとめていきます。

## 週刊GeoAI

「週刊GeoAI」は、GeoAIに関する1週間分のニュース・論文・事例を、毎週金曜にSubstackで配信する日本語ニュースレターです。

本サイトでは、週刊GeoAIのバックナンバーを保存・公開します。
