## 週刊GeoAI

「週刊GeoAI」は、GeoAIに関する1週間分のニュース・論文・事例を、毎週金曜にSubstackで配信する日本語ニュースレターです。

週刊GeoAIのバックナンバーはSubstackに集約しています。
