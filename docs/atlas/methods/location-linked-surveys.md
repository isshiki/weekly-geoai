# 位置情報とアンケートを組み合わせる

イベントの参加者が何に満足し、どこを改善してほしいかを知りたいとき、位置情報で調査候補者を選び、アンケートで意見を聞く方法がある。位置情報だけから気持ちや消費額を読み取るものではない。

## 場所にいた人へ、後から聞く

| 段階 | 分かること・確認すること |
| --- | --- |
| 位置情報で抽出 | 指定エリア・期間・滞在条件に合う人を選ぶ。会場への入場や参加目的まで確定しない |
| アンケートを配信 | 満足度、再訪意向、消費額、改善要望を回答から知る |
| 対象を絞って集計 | 例えば観光目的の回答者を抽出する。回収全体と指標の分母を区別する |

## 7祭りの調査例

ジオテクノロジーズの2026年10月30日発表では、Geo-Researchを用い、トリマ利用者のうち対象地域に3分以上滞在した人へアンケートを配信した。エリアは主要駅中心の半径6km、長岡は花火大会開催場所中心の半径6kmである。5,338人は回収総数で、掲載された満足度46.2〜91.5%・再訪意向86.5〜95.9%は、そのうち祭りに観光目的で訪れた回答者の集計である。

交通改善の要望は7祭りすべてで挙がった。消費額の中央値5,000〜15,000円は交通費を除く推計値である。福島では悪天候による一部中止があり、回答者構成も異なるため、祭りの優劣を示すランキングとして読まない。

## 活用と限界

開催後に聞けば滞在全体の経験を尋ねられ、次回の交通案内や会場設備の改善を考える材料になる。一方、アプリ利用者の回答が来場者全員の代表になるとは限らない。提供者による自主調査であり、本Atlasでは再集計していない。ここで説明する位置情報と調査の組み合わせにAIは必須ではない。

## 調査結果を広告の見直しにつなぐ

ジオテクノロジーズは2026年11月2日、Geo-ResearchとGeo-Promotion Adsを組み合わせる広告運用パッケージを発表した。利用者の同意に基づく来訪・回答データを配信対象の設計に使い、初回と3か月ごとの調査で見直す構成である。

位置情報は「訪れたか」、アンケートは「どう感じたか」を知る材料になる。ただし、広告後に来訪や認知が増えても、それだけで広告が原因とはいえない。季節や別の施策、調査対象者の違いも確認する。これは提供会社によるサービス説明であり、広告効果の独立した検証結果ではない。
