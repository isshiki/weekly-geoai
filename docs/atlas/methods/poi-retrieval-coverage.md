# POI検索の取得効率と網羅性

返却件数に上限のあるPOI検索では、調査範囲の分け方によって呼び出し数と取りこぼしが変わる。API呼び出しを減らすことと、実在する施設を漏れなく取得することは、別々に評価する。

## 検索済み範囲を除く貪欲法

2026年9月28日公開のISPRS Annals論文は、Google Places APIの1回20件の上限を踏まえ、結果から探索済み範囲を判定し、未調査域へ検索を進める手法を示す。

| 対象 | 適応四分木の呼び出し数 | 提案法 |
| --- | ---: | ---: |
| 渋谷区 | 2,842 | 1,067 |
| 千葉市 | 1,503 | 610 |

論文の表2は、取得データに基づき従来法をシミュレーションした比較である。適応四分木に対して約60％減、50m固定格子に対して最大約99％減と報告するが、地域・密度・比較法に依存する。

取得率の基準は提案法が収集したデータであり、地域の全実在店舗を真値とした精度ではない。同一座標に多数の店舗がある場合などの取りこぼしにも注意する。API利用と取得データの保存・公開の条件は、アルゴリズムの有効性とは別に確認する。
