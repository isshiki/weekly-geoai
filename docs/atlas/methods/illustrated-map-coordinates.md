# 手描き地図の座標校正と表示

手描き地図へ実地点を配置するときは、地理座標と画像内座標の対応に加え、画面上の拡大縮小も管理する必要がある。「もしも天気」の実装記事は、180地点の表示で生じた問題を整理している。

## 座標と描画の確認箇所

| 段階 | 記事の実装・対策 |
| --- | --- |
| 緯度経度から画像内へ | 約20〜30の基準点を対応付け、薄板スプラインで補間する |
| 海岸付近の表示 | 線の太さ程度にはみ出す点を、マスク画像に基づき最寄りの陸地へ寄せる |
| 画像と描画領域 | コンテナの縦横比を画像実寸に合わせ、余白によるCanvasとのずれを除く |
| ズーム後の描画 | 操作が止まった時点で、必要な解像度のCanvasを描き直す |
| マーカーの位置 | 拡大済みのサイズへ倍率を二重適用せず、ズームされない外側要素を基準にする |

陸地へ寄せる処理はイラスト上の表示調整であり、元の地理座標の精度向上とは区別する。地図画像を差し替えるたびに基準点を測り直し、変換式を再作成して180地点を目視確認している。

## 表示品質の確認

記事では、ズーム倍率の二重適用を検出する回帰テストも追加した。凡例は背景色と文字色を組み合わせて指定し、テーマ切り替え時の可読性を確保する。

[座標参照系](../concepts/coordinate-reference-systems.md)とは別に、画像と画面の座標系を区別して点検する事例である。
