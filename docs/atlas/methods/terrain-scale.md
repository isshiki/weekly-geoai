# 標高タイルによる地形指標と測定スケール

標高から傾斜や谷・尾根の傾向を計算するときは、標高差を測る距離や周囲を集計する範囲を明示する。値はデータの解像度・欠損と測定スケールに依存する。

## 基線長で変わる傾斜

sz_takの2026年9月29日の実装記事は、国土地理院の標高タイルから傾斜を計算し、大阪の低地で基線15.7mなら7.6度、125.6mなら0.4度になったと報告する。記事で示す測定例であり、今回再実測したものではない。

短い基線では局所的な起伏やデータのノイズの影響を受ける。長い基線では局所的な変化が平均化されるため、長ければ常に正しいとも限らない。傾斜だけでなく基線長・DEMの種類・有効サンプル数を残し、用途に合う尺度かを確認する。

## 欠損と推定値を区別する

| 処理 | 確認点 |
| --- | --- |
| 標高の読み取り | 符号付き24bitを解釈し、無効値を0mに置き換えない |
| レイヤー選択 | HTTP成功だけでなく、対象地点に有効な標高があるか確認 |
| 谷・尾根の傾向 | 周囲との標高差と近傍関係を使い、絶対標高と区別 |
| 地図色からの水域距離 | 池・プールと河川を区別できず、暗渠や配色変更にも弱い |

地図上の水色から測る距離は、正確な河川距離として扱わない。探索範囲内で見つからなかった場合も「遠い」と断定せず不明として扱う。記事の実装例を整理したもので、個別地点の地形判定を保証するものではない。
