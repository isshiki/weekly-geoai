# 街歩きによるバリア情報マッピング

街歩きで段差や傾斜などを確認し、移動のしやすさに関する情報を地図へ登録する方法である。道路の形状だけでは捉えにくい現地の状況を参加者が記録する。

## 門司港で予定されている取り組み

OpenStreetMap Japanの告知では、Divers ProjectとCode for Kitakyushuが2026年10月31日に門司港駅周辺で街歩きイベントを開催予定である。会場は門司生涯学習センターと案内されている。

| 活動 | 内容 |
| --- | --- |
| 体験 | 車いすで街を移動し、普段気付きにくい段差や傾斜を確認する |
| 記録・共有 | 気付いたバリア情報をDivers MapとOpenStreetMapへ登録する |
| 利用の目的 | 車いす・ベビーカー利用者や高齢者などの移動に役立てる |

Divers Mapは通りやすい道の共有に特化したWebアプリとして紹介されている。告知は開催前の予定であり、登録件数や改善効果などの実績は示されていない。

[Valhalla](../tools/valhalla.md)のような経路計算の仕組みと、現地で確認する通行条件は、併せて考えるべき別の要素である。

## 地下の通路は上下の接続も記録する

大手町の地下空間を歩く『散歩の達人』の記事は、地下鉄5路線とビルがつながる通路を現地で読み解く例である。平面図で交わって見える通路でも、階が異なれば直接行き来できない。

経路の資料にする場合は、通路の線だけでなく、階段・昇降設備と接続先の階を分けて記録する。これはAtlasでの整理上の提案であり、紹介された散策地図が車椅子対応や常時通行を保証するという意味ではない。

## 接続と通行できる時間を分ける

同連載の完結編は、大手町・丸の内／八重洲・有楽町／銀座を実地調査した地図を公開した。記事によると大手町駅C2b出口から東銀座駅6番出口までは地下通路で約2.5km、ビル地下を含む重複しない遠回りのコースは約12kmになる。距離は記事の報告値で、Atlasで再測定したものではない。

情報は2026年9月の調査時点であり、ビル地下は曜日・時間帯によって通れない場合がある。ネットワークとしてつながっていることと、特定の人が特定の時間に利用できることを区別する。これは[UGCoPの場所・時間の考え方](../concepts/ugcop.md#space-time)と関連する実務上の確認点であり、記事がUGCoPの実験を行ったという意味ではない。

記事が紹介する2028年の10駅連結は将来予定として扱い、現在通れる範囲に含めない。事業者側の計画は今回独立に確認していない。図面や写真は転載せず、原記事へ案内する。
