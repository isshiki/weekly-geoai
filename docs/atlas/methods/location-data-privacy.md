# 位置情報データのプライバシー保護

位置情報のプライバシー保護では、氏名やIDだけでなく、位置と時刻を組み合わせた履歴から個人を推測できる余地を考える。分析目的に必要な空間・時間単位を先に決め、複数の加工方法を組み合わせる。

## 加工方法と役割

| 方法 | 扱うもの | 留意点 |
| --- | --- | --- |
| 識別子の削除・置換 | 氏名、会員番号など | 詳細な移動履歴からの推測は残り得る |
| 地域・時間別の集計 | 個人単位の履歴 | 小さすぎる集団では推測の余地が残る |
| 粒度の調整 | 位置精度、時間幅 | 粗くしすぎると分析目的を満たせない |
| 少数セル・特異情報の抑制 | 少人数区画、珍しい履歴 | 一律に安全とする人数基準はない |
| ノイズ付加 | 公開する統計値 | 任意の乱数を足すだけで保護を保証できるわけではない |

差分プライバシーは、個人のデータが含まれるかどうかを出力から判別しにくくする考え方を数学的に定義する。集計やID置換だけで同等の保証が得られるものではない。
