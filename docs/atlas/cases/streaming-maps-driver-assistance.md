# 運転支援と地図の継続更新

車載地図では、道路・交通規制・POIなどの変化を継続的に届ける仕組みが、ナビゲーションや運転支援の基盤になる。HEREとNIOは2026年9月24日、欧州向け車種への協業拡大とストリーミングマップ技術の採用を発表した。

## 発表で確認した内容

- 対象としてFirefly、ET5、ET7、EL6、EL7、EL8を含む欧州向けラインアップを挙げている。
- 道路網の変更、交通規制、POIの新しい情報を継続配信する。
- NOAやNIO WorldModelを含む将来の運転支援・AI運転体験の基盤として位置付けている。

地図配信の採用と、将来の運転支援機能が全車種で利用可能になったことは区別する。発表には本ページで比較できる更新遅延や運転安全性の実測値はなく、車種別の機能提供時期も確認していない。
