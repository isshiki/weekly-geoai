# 歩行距離で見る最寄り駅と鉄道空白地帯

川や線路を渡れる場所が限られると、直線で近い駅が歩いて近いとは限らない。一色政彦の2つのWeb地図は、道路に沿った推計距離から駅へのアクセスを比べる事例である。ブラウザーで閲覧でき、町丁目や駅名から場所を探せる。

## 3種類の範囲を区別する

| 範囲 | 答える問い | 重なり・条件 |
| --- | --- | --- |
| 駅の縄張り | 歩いて最も近い駅はどこか | 推計距離が最短の駅へ割り当てる独自区分 |
| 徒歩15分圏 | この駅へ15分以内に歩けるか | 複数駅の圏域が重なることがある |
| 鉄道空白地帯 | どの駅へも20分を超えるか | この地図独自の定義。自治体の基準と区別する |

首都圏の縄張りマップは25m格子で判定し、80mを徒歩1分に換算する。15分より遠くても最寄り駅の縄張りに属し得る。境界の平滑化により、表示と元の格子判定が異なる場合がある。信号待ちや坂、実際の駅出入口の条件は反映していない。

## 延伸シナリオの面積と人口

東京の鉄道空白地帯マップでは、大泉学園町・大泉町などの対象区域は約5.94km²、人口は約6.3万人と推計される。人口は2020年国勢調査の250mメッシュから面積で配分した概数である。

大江戸線の予定3駅を概略位置に置く想定では、現在の空白地帯の面積の約92％が徒歩圏に入る。これは住民の92％が対象になるという意味ではなく、確定した駅位置や開業後の実測でもない。ここでの徒歩20分超と、練馬区の最寄り駅から1km以上という定義は異なる。

## 利用前に確かめること

道路データの欠け、駅への接続位置、移動速度、対象地域の端を確認する。縄張りは公的な駅勢圏や実際の利用者分布ではなく、通勤先や列車の頻度も表さない。2記事の説明を確認した整理であり、経路計算や人口推計を再実行したものではない。
