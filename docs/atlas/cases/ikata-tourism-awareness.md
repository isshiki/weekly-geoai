# 伊方町：人流と観光地の認知

愛媛県伊方町とジオテクノロジーズの調査は、位置情報から分かる来訪と、アンケートから分かる地名の認知を組み合わせた事例である。「そこへ行った」と「その町を知っている」は同じではない。

## 行動と意識を分けて測る

2026年10月13日の発表は、九州から来訪した回答者の43.7％が伊方町を知らない・場所が分からないと報告する。佐田岬やフェリーの経路を知っていても、自治体名と結び付かないことが課題として挙げられた。

| 調査 | 対象と確認できること |
| --- | --- |
| Geo-Peopleの人流 | 2025年3月8日〜2026年3月7日に30分以上滞在した非居住者6,695人。来訪実態を集計 |
| 来訪者アンケート | 同期間に5分以上滞在した人を対象に2026年3月に実施。回収927件。認知や意向を確認 |

滞在条件と回答者の範囲が異なるため、二つの数値を同じ母集団の集計として直接結合しない。43.7％も全来訪者の悉皆調査結果ではない。位置情報から気持ちや来訪目的を直接推測せず、別の調査で確かめる点が参考になる。

## 分析から施策へ

町名と現地体験を結び付けるため、トリマの指定地点でのチェックインと情報提示を使う実証実験を実施している。これは認知・回遊を促す施策の開始報告であり、消費や観光客数の増加を実証した結果ではない。
