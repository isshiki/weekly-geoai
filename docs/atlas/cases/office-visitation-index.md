# 人流データによるオフィス訪問指数

Placer.aiのNationwide Office Building Indexは、米国の約1,300棟の主要商業オフィスビルの訪問動向を人流データから分析する指数である。

## 対象と読み方

商業オフィスと、1階に店舗がある商業オフィスを対象とする。政府庁舎や住宅・商業の複合用途ビルは含まない。訪問数の増減を示すため、全米の労働者の出社率と同一視しない。

## 2026年8月の例

| 比較基準 | 全米の訪問数増減 |
| --- | --- |
| 2025年8月 | +6.2％ |
| 2019年8月 | -32.5％ |

同じ月の前年から増えても、2019年の水準へ戻ったとは限らない。記事は2026年8月の営業日が21日、2019年8月が22日だったことも示している。出社義務化が訪問を支えたという説明は発行元の解釈であり、この指数だけで因果効果を特定するものではない。
