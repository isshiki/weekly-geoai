# マクドナルド価格帯マップ

「マクドナルド価格帯マップ」は、全国のマクドナルド店舗をビッグマックの価格帯で色分けした非公式の地図サービスである。POIに価格という変化しやすい属性を付与し、現在地や店舗設備と組み合わせて検索できる事例として捉えられる。

## 地図で扱っている情報

確認時点では、ビッグマックの価格を500円、520円、530円、550円、600円の5段階で表示する。現在地付近の店舗一覧に加え、価格帯と次の条件で絞り込める。

- ドライブスルー、朝マック、駐車場、24時間営業
- デリバリー、McCafé、現在営業中

価格は運営者が独自に調査したもので、全国の店舗情報はおよそ10日ごとに更新すると説明されている。公式情報ではないため、実際の購入前には店舗または公式アプリで最新価格を確認する必要がある。

## POI活用としてのポイント

店舗の位置だけを示すのではなく、「商品価格」「設備」「営業状態」をPOI属性として検索条件にしている。利用者の現在地から近い店舗を並べることで、距離と価格のどちらを優先するかという意思決定も支援する。

一方、価格や営業時間は更新頻度が高く、取得時刻と出典が品質を左右する。こうした地図では、位置精度だけでなく、属性の更新間隔、欠損、公式情報との差を明示することが重要である。
