# ブラックフライデーの小売来訪分析

Foursquareが2025年の米国ブラックフライデーを対象に、店舗来訪の地域差を分析した事例である。総小売来訪量で上位25のDMA（市場エリア）を選び、通常の金曜日からの増加率で比較している。

## 比較方法

対象日は2025年11月28日で、比較基準は直前4回の金曜日（10月31日、11月7日・14日・21日）の平均来訪量である。

増加率は「対象日の来訪量 ÷ 比較基準の平均来訪量 − 1」を百分率で表したものとして読む。市場を選ぶ基準の総量と、順位に使う増加率を区別する。

| DMA | 基準の金曜日平均からの増加率 |
| --- | --- |
| Chicago | +57.77％ |
| Orlando | +55.56％ |
| Seattle-Tacoma | +12.51％ |

この比較は来訪動向を示すものであり、購入額や広告の因果効果を直接測ったものではない。発行元の市場分類ではHoustonが複数区分に登場し、区分の閾値と掲載市場にも整合しない箇所があるため、分類をそのまま再利用せず、数値表と比較方法を参照する。
