# 旅客船のAIS位置情報の可視化

旅客船の位置情報を集計し、日本周辺の海上交通を地図で示す事例である。2026年9月19日の投稿で、machi_measureがAIS位置情報による可視化を報告した。

## 確認できた範囲

投稿本文で確認できるのは、日本周辺の旅客船を対象に位置情報を集計・可視化したという説明である。集計期間、受信範囲、欠測処理、船種の抽出条件、密度の計算方法は本文に記載されていない。

## 再利用する際の確認観点

以下は本事例を踏まえた編集上の確認観点であり、投稿者の処理手順を示すものではない。

- 集計対象期間と受信範囲を確認する。
- 位置情報の点数と、船舶数・運航回数を区別する。
- 航跡が見えることと、定期旅客航路として運航していることを区別する。

共有要約にあった「約6年分」や個別地域の航路解釈は、今回の本文確認だけでは裏付けられないため採用していない。
