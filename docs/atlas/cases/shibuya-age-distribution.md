# 渋谷の街区別年代構成と人流の読み方

街全体のイメージと、実際に歩く街区の人流は一致するとは限らない。帝国データバンクは2026年9月21日、モバイル空間統計を使い、渋谷駅周辺の年代構成を比較した。

## 分析の単位

対象期間は2025年4月から2026年3月、対象範囲は駅を中心とする750メートル四方である。さらに250メートル四方の街区に分け、平日と休日を比較している。

| 観察する範囲 | 原報が示す特徴 |
| --- | --- |
| 駅周辺全体 | 休日の20代以下の割合は47.8％ |
| 西側のセンター街周辺など | 若年層の割合が高い |
| 東側の街区 | 30～50代の割合が高いエリアがある |

出典：帝国データバンクの原報。居住人口ではなく、対象地域に滞在する人の構成を扱う。

## 他の都市にも使える読み方

- 街全体の平均と、目的地周辺の構成を分ける。出店や広告の対象を考える場合も、駅名だけで商圏を一括りにしない。
- 構成比と人数を分ける。ある年代の割合が高くても、その年代の人数が以前より増えたとは限らない。
- 空間的な違いと時間的な変化を分ける。今回の期間内比較だけで、過去数十年の「若者離れ」を否定・肯定することはできない。
- 年齢の収録範囲、集計時間帯、滞在の定義、推計方法をそろえて比較する。公開本文だけではこれらの詳細を再現できない。

再開発や施設の配置が年代構成に関係するという原報の考察と、それらが変化を引き起こしたという因果関係の実証は区別する。
