# 来訪傾向を使う音声広告セグメント

来訪先や移動傾向から推察した興味関心を、音声広告の配信対象に結び付ける事例である。

## リアル行動アフィニティ

unerryとradikoは2026年9月16日、両社のデータを連携する新セグメントを発表した。ライフステージ、趣味、行動傾向などに基づく20種類以上の区分をradiko audio Adで利用する。

検索・閲覧履歴に加え、実世界で訪れる場所を広告配信の判断材料にする。推定された関心や属性は、本人の申告や確定情報とは区別する。

## データの扱い

発表では、同意に基づく位置情報を個人が特定されない形で利用すると説明している。これは提供企業の説明であり、技術的な匿名化方式の検証結果ではない。配信可否や対象規模は案件ごとに異なる。
