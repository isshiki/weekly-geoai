# 富士山閉山期の人流分析

Location AIがスマートフォンの位置情報を解析し、富士山の閉山期の来訪傾向を可視化した事例である。2026年9月12日放送のテレビ朝日「サタデーステーション」で使われ、同社が9月14日に報告した。

## 確認したポイント

- Location Engineで山頂付近の人流をヒートマップ化した。
- 閉山直後の9月中旬、ご来光の時間帯に山頂付近へ人が集まる傾向を報告している。
- 2月やゴールデンウィーク前後にも人流を把握したとしている。

同社記事の「1日で数十以上の人流データ」という記述を、そのまま実人数や全登山者数に読み替えない。記事本文だけでは観測対象年、捕捉率、人数への推計手順の詳細を確認できないため、放送年と分析対象年も分けて扱う。

## 安全対策検討への利用

2026年9月22日、Location AIは読売新聞の混雑報道と静岡県の閉山期安全対策ワーキンググループで分析が利用されたと発表した。通行ルートや滞在傾向を、安全対策の検討材料として提供した事例である。

同社は昨秋から今夏にかけての閉山期の登山者を約1万4,000人と推計している。観測ログ数や悉皆調査の実人数とは異なり、記事だけでは推計方法・誤差の詳細を確認できない。

登山届の義務化や侵入防止柵の改良は検討案として紹介されている。導入済みの制度や効果が実証された対策として扱わない。開山期の特定時間帯への集中と閉山期の登山実態も、異なる分析対象として読む。
