# 来店検知を使う位置連動リテールメディア

位置連動リテールメディアは、店舗への来訪を検知し、その場所とタイミングに応じて情報を配信し、購買や別施設への来訪まで効果を測る取り組みである。オンライン上のリーチやクリックだけでなく、実店舗での行動を評価対象にする。

## 基本的な流れ

1. GPSや店内ビーコンなどから、利用者の同意範囲内で来店を検知する。
2. 周辺人流、店舗立地、商品取り扱いなどから配信対象と内容を決める。
3. 対応するアプリを通じ、来店時にプッシュ通知を配信する。
4. 広告接触と購買、または対象施設への来訪を集計し、効果を評価する。

## unerryとローソンの例

unerryは2026年9月、ローソン店内のChargeSPOTなどに搭載されたビーコンとBeacon Bankを連携し、来店時のリアルタイムプッシュ広告と購買計測サービスを開始したと発表した。

周辺人流と立地から店舗をオフィス街、住宅街などのクラスターへ分け、商品配架率の高いエリアへ配信を絞る。消費財では広告接触後の購買、店舗外の施設やイベントでは広告視聴後の来訪を測るとしている。発表では、利用データで特定の個人を識別しないとしている。

## 評価するときの確認点

| 項目 | 確認内容 |
| --- | --- |
| 来店判定 | 検知距離、滞在条件、誤検知、従業員や通過者の除外 |
| 配信母集団 | 対応アプリ、同意率、地域・属性の偏り |
| 購買との接続 | 広告接触群と対照群、計測期間、他施策の影響 |
| 在庫・配架 | 対象商品が実際に購入できた店舗と時間帯 |
| プライバシー | 同意、利用目的、保持期間、集計粒度、オプトアウト |

「個人を識別しない」という説明だけで十分とは限らない。位置履歴と購買は組み合わせによって再識別リスクが高まるため、取得段階の同意と、集計後の最小化を別々に確認する必要がある。
