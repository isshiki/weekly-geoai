# 小売出店候補地のロケーションインテリジェンス

小売・飲食の出店候補地分析では、候補地点ごとの売上だけでなく、投資リターンや既存店とのカニバリゼーションも同時に評価する。人口統計、競合、交通、自社実績などを空間的に結び付け、複数の制約を満たす地点を絞り込むロケーションインテリジェンスの事例である。

## 分析の組み立て

候補地点の評価には、一般に次のような情報を組み合わせる。

| 情報 | 評価への使い方 |
| --- | --- |
| 人口統計・商圏特性 | 想定顧客の規模や構成を捉える |
| 競合と補完関係にある店舗 | 競争の強さと周辺への集客力を捉える |
| 交通量・道路上の位置 | 到達しやすさや視認性を捉える |
| 犯罪などの周辺環境 | 運営上のリスクを捉える |
| 自社の店舗・売上データ | 売上予測と既存店への影響を補正する |

CRE Dailyが紹介したBainのVantageの例では、地点別の売上、キャッシュ・オン・キャッシュ・リターン、カニバリゼーションを機械学習で推計し、最低売上や最大カニバリゼーション率などの条件に合う候補地を比較している。

## 国内導入例：SENSY GeoScope

SENSYは2026年9月、食品スーパーマーケットのベルクで、AI店舗開発支援サービス「SENSY GeoScope」の本格運用を開始したと発表した。地図上で出店候補地を指定し、自社POS、商圏、競合店舗、人口・世帯データなどから売上を予測する。

売上予測とともに、商圏人口、将来人口、競合、類似店舗、立地条件をまとめたレポートを生成する。売場面積、駐車台数、併設テナント、営業時間、競合店の出退店といった条件を変え、推定売上への影響を比較するシナリオ機能も備える。

発表によると、ベルクとの検証対象では予測誤差率が中央値で7%台となった。この数値は対象店舗、期間、誤差指標の詳細を伴う一般性能値ではなく、発表された検証範囲の結果として扱う。ベルクは外部調査、現地確認、担当者の経験と組み合わせ、候補地の初期評価に利用している。

## 予測だけでは埋まらない情報

データが豊富でも、短期的な観光客の流れ、区画単位の歩行動線、地域特有の事情などを十分に捉えられない場合がある。モデルの順位を最終判断とせず、現地調査、不動産実務、地域知識によって候補地を検証する必要がある。

予測値を利用するときは、目的変数、学習期間、更新頻度、候補地の比較範囲を確認する。売上が高い地点と投資効率が高い地点は必ずしも一致せず、既存店への影響を含めると順位が変わり得る。

## 開業後の来訪傾向による検証

技研商事インターナショナルは2026年9月23日、KDDI Location Analyzerを使ったイオン八王子滝山の分析を公開した。対象は6月26日から9月19日で、数値は位置情報に基づく推計である。

平日と休日の平均来訪者数、年代構成、居住地を組み合わせ、広域から週末に訪れる傾向を考察している。記事の1日平均は平日約1,900人、土日・祝日約3,000人である。

このような比較は出店時の想定商圏を開業後に検証する材料になる。ただし来訪者の年代や人数から、購買額・来訪目的・家族同伴を直接確認することはできない。期間中の人数が重複を除いた実人数か延べ来訪か、捕捉率や推計方法も確認する必要がある。

原文では圏外来訪と居住者の比率が本文で約15倍、結論で約30対1と一致しないため、この比率は分析根拠として採用しない。
