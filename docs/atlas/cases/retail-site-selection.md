# 小売出店候補地のロケーションインテリジェンス

小売・飲食の出店候補地分析では、候補地点ごとの売上だけでなく、投資リターンや既存店とのカニバリゼーションも同時に評価する。人口統計、競合、交通、自社実績などを空間的に結び付け、複数の制約を満たす地点を絞り込むロケーションインテリジェンスの事例である。

## 分析の組み立て

候補地点の評価には、一般に次のような情報を組み合わせる。

| 情報 | 評価への使い方 |
| --- | --- |
| 人口統計・商圏特性 | 想定顧客の規模や構成を捉える |
| 競合と補完関係にある店舗 | 競争の強さと周辺への集客力を捉える |
| 交通量・道路上の位置 | 到達しやすさや視認性を捉える |
| 犯罪などの周辺環境 | 運営上のリスクを捉える |
| 自社の店舗・売上データ | 売上予測と既存店への影響を補正する |

CRE Dailyが紹介したBainのVantageの例では、地点別の売上、キャッシュ・オン・キャッシュ・リターン、カニバリゼーションを機械学習で推計し、最低売上や最大カニバリゼーション率などの条件に合う候補地を比較している。

## 国内導入例：SENSY GeoScope

SENSYは2026年9月、食品スーパーマーケットのベルクで、AI店舗開発支援サービス「SENSY GeoScope」の本格運用を開始したと発表した。地図上で出店候補地を指定し、自社POS、商圏、競合店舗、人口・世帯データなどから売上を予測する。

売上予測とともに、商圏人口、将来人口、競合、類似店舗、立地条件をまとめたレポートを生成する。売場面積、駐車台数、併設テナント、営業時間、競合店の出退店といった条件を変え、推定売上への影響を比較するシナリオ機能も備える。

発表によると、ベルクとの検証対象では予測誤差率が中央値で7%台となった。この数値は対象店舗、期間、誤差指標の詳細を伴う一般性能値ではなく、発表された検証範囲の結果として扱う。ベルクは外部調査、現地確認、担当者の経験と組み合わせ、候補地の初期評価に利用している。

## 予測だけでは埋まらない情報

データが豊富でも、短期的な観光客の流れ、区画単位の歩行動線、地域特有の事情などを十分に捉えられない場合がある。モデルの順位を最終判断とせず、現地調査、不動産実務、地域知識によって候補地を検証する必要がある。

予測値を利用するときは、目的変数、学習期間、更新頻度、候補地の比較範囲を確認する。売上が高い地点と投資効率が高い地点は必ずしも一致せず、既存店への影響を含めると順位が変わり得る。

## 開業後の来訪傾向による検証

技研商事インターナショナルは2026年9月23日、KDDI Location Analyzerを使ったイオン八王子滝山の分析を公開した。対象は6月26日から9月19日で、数値は位置情報に基づく推計である。

平日と休日の平均来訪者数、年代構成、居住地を組み合わせ、広域から週末に訪れる傾向を考察している。記事の1日平均は平日約1,900人、土日・祝日約3,000人である。

このような比較は出店時の想定商圏を開業後に検証する材料になる。ただし来訪者の年代や人数から、購買額・来訪目的・家族同伴を直接確認することはできない。期間中の人数が重複を除いた実人数か延べ来訪か、捕捉率や推計方法も確認する必要がある。

原文では圏外来訪と居住者の比率が本文で約15倍、結論で約30対1と一致しないため、この比率は分析根拠として採用しない。

## 候補地の選定からデータ要件を見直す

技研商事インターナショナルの9月29日のTHE NOVEL開発記事は、2026年1月8日の会議を振り返る。店舗形態ごとに人口・駅の乗降客数・競合などで候補を絞り、売上予測で順位付けする業務が、有償POI・駅データを再検討するきっかけとなった。

利用者の問いは「どこに出せるか」に加え「あと何店舗出せるか」である。会議で決まったのはデータの採用や実装ではなく、必要な成果物・業務手順、画面、他機能との共通化、費用を確認することであった。完成した売上予測機能の精度検証や、有償データ採用済みの報告として扱わない。

## 店舗評価を地域指標へ集計する

DataForSEOの2026年9月29日更新記事は、ミラノ周辺46自治体の飲食店8,706件をPostGISで3,746国勢調査区へ結び付けた。口コミ件数で重み付けした平均評価と、人口1,000人当たりの店舗数を計算する。未評価店舗は密度に含め、平均評価からは除外する。

約3.8ドルは記事の取得例の費用である。口コミによる地域評価は、居住者全体の満足度や将来の売上そのものではない。記事は生の店舗一覧の再公開を避け、集計結果を公開するよう案内している。

## 直線距離から移動時間の商圏へ

Mapboxの2026年10月1日のTableau事例は、道路網に沿った到達圏で商圏を調べる。18店舗・10段階の移動時間・820国勢調査地区を組み合わせ、約14万8,000回の交差計算をTableau Prep Builderで事前に行い、所得情報とともに操作できる画面へつなぐ。

同記事は電気工事業者とEV充電施設の移動時間行列から、対応可能な業者とサービス空白地域を表示する例も紹介する。円形の距離圏と道路網上の到達圏を区別し、重い計算を画面操作の前に済ませる設計の参考になる。

## 山田うどんの出店分析支援

SENSYの2026年10月2日発表は、山田食品産業へのSENSY GeoScope導入を紹介する。人流・人口・周辺施設・競合などを使い、候補物件の売上予測と正負の要因を自動算出し、候補選定や社内説明に利用する。

同社は収集・分析の作業が丸1日〜数日から数十秒程度へ短縮したと説明する。これは導入企業と提供者の報告であり、予測誤差や検証用データの条件は示されていない。投資回収シミュレーションと適正家賃の可視化は今後の予定である。

## 決済・人流・地域統計を組み合わせる

技研商事インターナショナルの2026年10月6日発表は、オリコの加盟店向け出店支援「Orico Area Navi」を紹介する。同社によると、約1,000万人規模・10年以上のクレジットカード決済データと地域統計・人流を組み合わせている。

MarketAnalyzer 5は決済と統計の統合・売上予測、KDDI Location Analyzerは自社と競合の来訪客層の重複、MarketAnalyzer Satelliteは商圏や出退店の初期確認に使われる。購買と来訪は異なる情報であり、単に施設が多い場所を選ぶ方法との違いを読む事例になる。

発表には予測誤差や評価用データの分け方、個人単位での結合方法は示されていない。人数の規模だけから地域・業種の代表性を判断せず、すべての決済者に移動履歴を結び付けているとも解釈しない。

## 施設数の増減と営業実態を分ける

ルミエールの2026年10月8日発表は、衛生行政報告例の2014〜2024年度を比較し、銭湯36.4％減、クリーニング店36.1％減、簡易宿所70.4％増と報告する。別途69業種の地域別施設数や市場規模の調査ページを公開し、一部業種を除き市区町村別の無料Excelを申込制で提供する。

この比較の単位は届け出・許可数であり、営業中の店舗数と一致するとは限らない。簡易宿所と住宅宿泊事業法の届出住宅も別の集計対象である。公的統計とPOIを比較する際は、業種分類、時点、営業状態、地域単位を確かめ、施設数の減少だけから出店余地を判断しない。Excelの取得や原統計の再集計は行っていない。
