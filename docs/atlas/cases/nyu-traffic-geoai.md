# 交通予測・空間分析・対話を組み合わせるNYUの研究

NYU Tandonが紹介する研究は、交通量を予測するモデル、混雑の空間分布を調べる処理、担当者が質問する対話画面を組み合わせたものである。都市計画担当者が予測や混雑箇所を調べる用途を想定している。

## 3つの役割を分ける

| 要素 | 役割 |
| --- | --- |
| LSTMによる時系列予測 | 過去の交通観測から将来の交通量を推定する |
| H3とクラスタリング | 六角形の区画を使い、交通が集中する場所を分析する |
| ローカルのLLaMA | 予測や混雑箇所を含むプロジェクトの知識ベースを、質問を通して参照する |

LLMへの質問機能と交通量を予測するモデルは別の役割である。対話しやすさと予測精度を分けて評価する必要がある。

## 報告された結果と限界

2026年9月22日の大学発表によると、2009〜2024年の観測データを使い、2021〜2024年を検証対象とした。LSTMの平均予測誤差は約343台／日で、ARIMAの約418台／日から約18％小さかった。この条件での比較であり、LLMによる精度改善や別の都市での性能を示す値ではない。

ローカル実行は組織内にデータを保つ設計だが、それだけでアクセス管理などが不要になるわけではない。実務の都市計画担当者による大規模な試験は未実施とされる。本ページは大学の紹介記事を確認した範囲であり、論文全体の精査や結果の再現は行っていない。
