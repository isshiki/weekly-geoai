# pricemap

pricemapは、同じチェーン内で異なる店舗別価格を地図上で比較できる、個人運営の非公式サービスである。POIに商品価格という変化しやすい属性を付け、現在地や店舗設備と組み合わせて探せる事例として捉えられる。

## 対応チェーンと比較対象

2026年9月8日の確認時点では、6チェーンに対応している。

| チェーン | 比較の目安となる商品・価格区分 |
| --- | --- |
| スターバックス | トールラテの店内価格ランク |
| マクドナルド | ビッグマックの価格ランク |
| ガスト | 価格パターンとチーズINハンバーグ |
| スシロー | 最低価格の皿 |
| びっくりドンキー | レギュラーバーグディッシュ Sサイズ |
| コメダ珈琲店 | コメダブレンドのイートイン価格 |

チェーンごとに価格帯の定義、絞り込み条件、店舗一覧が異なる。マクドナルド版では、現在地付近の店舗、価格帯、ドライブスルー、朝マック、駐車場、24時間営業などを組み合わせて検索できる。

## POI活用としてのポイント

店舗の位置だけでなく、「商品価格」「設備」「営業状態」をPOI属性として検索条件にしている。利用者は近さと価格を同じ地図で比較できるため、距離だけでは決められない店舗選択を支援する。

一方、価格や営業時間は更新頻度が高い。掲載価格は独自調査時点の情報であり、公式情報ではない。位置精度だけでなく、属性の取得日、更新間隔、欠損、公式情報との差を明示することが重要である。
