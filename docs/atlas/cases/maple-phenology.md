# 紅葉時期の変化と空間補間

生物季節観測の地点データを空間補間すると、観測点の間を含む分布を比較できる。ただし、観測値と推定面の値は区別して読む必要がある。

## かえでの紅葉日を比較した例

ESRIジャパンの2026年9月28日の記事は、気象庁のデータから1955〜1964年と2015〜2024年を比較した。各期間に異常値を除く3年以上の観測がある地点の平均日を求め、緯度・標高を考慮するArcGIS ProのEBK回帰予測で補間した。

| 集計対象 | 記事で示された結果 |
| --- | --- |
| 都市の観測データ | 札幌18日、仙台20日、東京17日、名古屋12日、大阪11日の遅れ |
| 作成した予測面の平均 | 10月24日から11月17日へ変化 |

予測面の平均は、全国の実測値だけを平均したものではない。森林限界やかえでの分布域を考慮しておらず、生育しない高標高域にも値が出る。観測点から離れた地域や山地では、具体的な日付より相対的な傾向として読むよう記事は説明している。

## 時系列予測と空間補間を組み合わせる

2026年9月30日の続編は、1993〜2025年の46地点の観測から、地点ごとに誤差の小さい時系列予測モデルを選び、2026年の紅葉日を予測する。EBK回帰予測で地点間へ広げ、100回のシミュレーションから中央値と早い側の5パーセンタイルを示した。早い側の値が、中央値より正確という意味ではない。

| 読み分ける点 | 記事の条件 |
| --- | --- |
| 気温の説明変数 | CHELSA-monthlyの1993〜2021年の10月平均気温。2026年秋の気象予報ではない |
| 交差検証 | 平均絶対誤差は約7日、RMSEは約8日 |
| 地理的な限界 | 山間部の観測が少なく、森林限界やカエデの分布域もマスクしていない |

地図上の日付は推定値であり、山地や生育域外で同じ精度が得られるとは限らない。
