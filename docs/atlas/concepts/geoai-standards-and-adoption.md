# GeoAIの標準化と実務での採用

GeoAIの標準化を読むときは、規格の対象、発行・開発の段階、実装での採用を区別する。規格が存在することだけでは、利用中のツール同士が接続できることや、分析の品質が保証されることまでは分からない。

## 確認した規格と開発計画

2026年9月25日にISO/TC 211の公開カタログで確認した状況である。

| 対象 | 状況と扱う範囲 |
| --- | --- |
| ISO 19178-1:2025 | AI向け学習データの記述を扱う概念モデル。発行済み版があり、改訂作業も進んでいる |
| ISO 19178-2・19178-3 | JSON・XMLによる符号化を扱う開発中の文書 |
| ISO/AWI TR 19182 | GeoAIを地理情報標準へ取り込む方法を扱う開発中の技術報告書プロジェクト |

ISO/TC 211は学習データの共有・相互運用性や、データ・モデルのメタデータ、来歴、品質の記述を課題として挙げている。これらは特定企業のエージェント製品の機能一覧や、製品間の共通APIそのものとは区別する。

## 実務で確認すること

以下は公開資料を踏まえたAtlasの確認観点である。

- 何を交換する規格か。学習データ、モデル、処理結果、APIのどこが対象かを確認する。
- 対応する製品・ライブラリがあり、同じ版を読み書きできるかを確認する。
- データを往復変換したとき、座標参照系、分類、来歴、品質情報が保持されるかを試す。
- 適合試験や実装例を確認し、規格の発行数を普及率の代わりにしない。

企業の実装と標準化は関係するが、今回確認した資料だけでは企業主導による普及・停滞の程度は判断できない。規格全文の要件への適合性も本ページでは評価していない。

## 評価できる人材と知識基盤

ルンド大学が2026年10月7日に紹介したEU事業GENIUSは、4年間でGeoAIの知識・技能を整理し、共通の知識基盤と高度な人材育成の資源・手法を整える計画である。予算400万ユーロ、欧州20超の組織が参加する。

同大学は、モデルを使えることに加え、使用データ・結果の信頼性・不確実性を理解する必要を強調する。これは人材育成と産学連携の計画であり、新しい技術規格の成立や教材の完成を示す発表ではない。

## 業界の分類と教育を見分ける

LBMA Japanの2026年カオスマップは、6回目の改訂で「ジオAI」を独立カテゴリとした。位置情報とAIの組み合わせが業界内で一つの領域として扱われる例である。これは業界団体による事業分類であり、GeoAIの唯一の定義、技術規格、市場規模の測定とは区別する。

横浜市立大学・LBMA Japan・ゼンリンデータコムは、位置情報データ活用人材の育成でも連携している。教育・研究と産官学連携を扱うシンポジウムの開催案内は[10月14日の更新履歴](../../updates/2026-10-14.md)に記録した。技術の普及を追う際は、製品機能に加え、学ぶ機会や実務で評価できる人材の育成も確認する。
