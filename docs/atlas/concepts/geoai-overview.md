# GeoAIの全体像

GeoAIは、地理空間情報とAIを組み合わせ、場所に関する情報を抽出・予測したり、分析作業を支援したりする取り組みである。このサイトでは広くこの意味で使う。研究では、距離・近傍・地域差などの空間的な性質をモデルに明示的に取り込むことも重要な論点となる。[1]

## 二つの使い方を分ける

| 使い方 | 入力と出力の例 | 確かめること |
| --- | --- | --- |
| データにAIを適用する | 衛星画像から建物の範囲を抽出する。周辺人口や店舗情報から需要を予測する | 正解との違い、取りこぼし、地域・時期が変わったときの性能 |
| AIにGIS操作を支援させる | 自然言語の依頼から空間SQLや処理手順を作り、集計や地図作成を実行する | 入力・単位・結合条件・出力が依頼に合うか、同じ手順を再現できるか |

二つは組み合わせられる。例えば、AIが建物抽出モデルを実行し、その結果を地域別に集計することもある。操作が完了したことと、抽出や集計の結果が妥当なことは別々に確かめる。自律GISの研究には試作システムと事例実験があるが、それだけで任意の業務を正しく実行できるとはいえない。[2]

## GIS・統計・機械学習はどうつながるか

- **GIS**は、位置と属性を結び付け、検索・結合・集計・表示するための基盤となる。
- **統計と機械学習**には重なる手法がある。同じ回帰モデルも、関係の説明と未知の値の予測に使える。目的に合わせて評価を選ぶ。
- **リモートセンシング**は、衛星や航空機などから地表を観測する手段である。観測画像の解析はGeoAIの用途の一つである。
- **生成AI・エージェント**は、文章やコードの生成、道具の操作などを支援する。従来の空間演算や結果の検証と組み合わせて使う。

店舗数の集計や、避難所と浸水区域の重ね合わせは、通常のGIS処理でも実現できる。まず必要な入力・出力を決め、AIを使う効果と確認の手間を考える。
