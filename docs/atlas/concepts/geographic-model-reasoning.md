# 地理空間モデルの予測と地理的理解

地理空間モデルを使うときは、「値を当てたい」「関係を説明したい」「施策の効果を知りたい」のどれを目指すかを決める。位置を扱えることと、場所の成り立ちや変化を説明できることは同じではない。

## 同じ回帰モデルでも、問いが違う { #prediction-explanation-causality }

例えば、店舗の売上を周辺人口や駅からの距離で表す回帰モデルを考える。以下は目的を理解するための架空の例であり、実測結果ではない。

| 目的 | 問いの例 | 主に確認すること |
| --- | --- | --- |
| 予測 | 新しい候補地の売上をどれくらい当てられるか | 未使用の地域・時点での誤差、単純な基準との比較 |
| 関係の説明 | 人口や駅からの距離と売上には、どのような関係があるか | 変数の定義、係数の不確実性、地域や集計単位を変えたときの安定性 |
| 因果効果の推定 | 同じ条件の地域で施策を行ったら、売上はどれだけ変わるか | 比較対象の作り方、交絡、介入と結果の時間順序などの仮定 |

統計と機械学習を「説明専用」「予測専用」に固定する必要はない。同じ手法でも、目的によってデータの集め方、モデルの選び方、最終的な検証が変わる。「説明」という言葉も、観測された関連の説明か、介入による変化の説明かを明示する。

予測への寄与を示す特徴量重要度やSHAPを使っても、それだけで原因は分からない。例えば「店が多い場所ほど人流が多い」という関係は、店を増やす効果とは限らない。人が多い場所に店が集まることや、交通利便性など共通する別の要因も考えられる。SHAP公式資料も、通常の予測モデルの説明をそのまま因果効果と読まないよう注意している。

## 地理空間データで追加する確認

- **地域差**：同じ変数と結果の関係が別地域でも成り立つとは限らない。
- **集計単位**：町丁目と市区町村で得られる関係が変わる可能性がある。区域の傾向を個々の住民の性質と同一視しない。
- **観測条件**：時点、センサー、データの収録範囲が違えば比較条件も変わる。
- **評価目的**：既存の地図の精度と、未知の地域や将来への予測性能を区別する。

具体的な分割方法は[分析結果の検証と適用範囲](../methods/spatial-analysis-validation.md)で整理する。

## 混同しやすいもの

| モデルが扱えるもの | それだけでは保証されないこと |
| --- | --- |
| 座標 | 場所の歴史・機能・他地域とのつながりの理解 |
| 高解像度の画像 | 分析範囲や集計単位が変わっても結論が妥当なこと |
| 高い予測精度 | 原因や介入効果の説明 |
| 世界規模の観測 | 地域・時期・センサーをまたぐ性能の均一性 |

## Living Geography Modelsという構想

2026年9月17日公開のarXivプレプリントは、地理をモデルの共通枠組みとして扱う概念的レビューを提示した。以下はその論文の構想である。

著者らは、場所と関係、変化の過程、スケール・来歴・不確実性などを明示し、自然環境と経済・社会の専門モデルを結ぶ構想を提案する。完成した単一モデルや性能向上を実証する報告ではない。

実務で読む際は、出力がどの地域・時間・集計単位で有効か、予測と因果説明を混同していないかを点検するための視点として利用できる。
