# 人流データの種類

人流データは、取得方式、加工後のデータ種別、人数の表し方を分けて捉える必要がある。GPSや携帯電話ネットワークは取得方式であり、位置点、滞在、人口集計、ODは加工段階や集計単位が異なるデータ種別である。

## 確認したポイント

- 個票レベルには位置点、軌跡・移動区間、滞在・訪問イベントがある。
- 集計データには人口・滞在人口、来訪者集計、ODがある。
- 同じ人数表記でも、観測されたサンプル数と母集団への拡大推計値は意味が異なる。
- 比較時は、取得方式、加工段階、集計単位、観測値か推計値かを確認する。
