# 国土数値情報

国土数値情報は、国土交通省が国土に関する基礎的な地理空間情報を全国統一的な形式で整備し、無償で提供するGISデータである。1974年に国土計画向けの整備が始まり、2001年から一般向けのダウンロード提供が行われている。

## 収録するデータ

2026年4月時点で約190種類が案内されている。主な分野は次のとおりである。

| 分野 | 例 |
| --- | --- |
| 土地利用 | 土地利用、森林地域、農業地域 |
| 行政地域 | 行政区域、学校区、人口集中地区 |
| 公共施設 | 役所、警察署、郵便局、医療・福祉施設 |
| 災害リスク | 洪水・津波・高潮浸水想定区域、土砂災害警戒区域 |
| 交通 | 道路、鉄道、駅別乗降客数、バスルート、空港、港湾 |
| 水域・地形 | 河川、湖沼、海岸線、ダム、標高・傾斜度 |
| 都市・経済 | 都市計画、地価、将来人口推計メッシュ |

データセットごとに対象年、更新頻度、提供形式、座標参照系、属性定義が異なる。一部には更新が終了した過去データもあり、約190種類すべてが同じ時点の現況を表すわけではない。

## 形式と利用

国土数値情報はShapefile、GeoJSON、GML、CSVなどで提供されるが、利用できる形式はデータセットごとに確認する。時系列比較や他データとの結合では、次を揃える必要がある。

- 対象年と基準日
- 行政界や路線などの定義変更
- CRSと位置精度
- 地物IDの継続性
- 欠測、未整備地域、更新終了の有無
- 利用約款と出典表記

国土交通省資料では、ダウンロード数は2009年度の約50万件から2025年度の約265万件見込みへ増加した。行政区域や土地利用細分メッシュなど、多くの分析で基礎となるデータが含まれる。

## GeoAIでの位置付け

国土数値情報はAIモデルそのものではなく、学習、推論、シミュレーション、結果検証へ地理的な文脈を加える基礎データとして利用できる。例えば、人口や施設と災害リスクを重ねる、土地利用を候補地評価の説明変数にする、行政区域へ結果を集計するといった使い方がある。

データを追加すれば自動的に精度が上がるわけではない。目的変数と時点が合っているか、空間解像度が十分か、リーケージや地域差がないかを検証する必要がある。また、国土交通省は衛星画像のAI判読を使った土地利用データ更新にも取り組んでおり、AIは利用側だけでなくデータ整備側でも使われる。

## 配布基盤を見る観点

人とAIエージェントの双方が使うには、ファイルの公開だけでなく、機械可読なメタデータ、条件検索、地図プレビュー、安定したURL、変更履歴、APIや一括取得手段が必要になる。2026年度は、国土数値情報ダウンロードサイトのガバメントクラウド移行とデータ変換パイプライン構築が進められていると報じられている。
