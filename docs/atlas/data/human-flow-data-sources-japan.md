# 日本で使える人流データ

日本で利用できる人流データは、公開データ・閲覧サービス、研究申請型データ、商用データという入手経路で整理できる。無料で閲覧できることと、データを取得・再配布できることは別である。入手しやすさだけでなく、集計値か軌跡か、実測か合成か、空間・時間粒度、利用条件を合わせて選ぶ必要がある。

このページは2026年8月時点の調査を基にし、2026年10月6日に国交省の全国人流データ、RESASの集計仕様、JoRASの申請条件・掲載データ、駅別乗降客数の単位を一次資料で確認した。全提供元・全契約条件を一括で再確認したものではない。年度、対象地域、料金、申請条件、提供形式は変わるため、利用時には各提供元で最新情報を確認する。

## 入手経路の違い

| 入手経路 | 主に得られるもの | 向いている用途 | 主な制約 |
| --- | --- | --- | --- |
| 公開データ・閲覧サービス | メッシュ人口、交通調査、通勤通学OD、駅統計 | 基礎集計、仮説探索、地域比較 | 集計済みが中心で、時期や粒度が限られる |
| 研究申請型 | 実GPS軌跡、トリップ、合成人口・擬似人流 | 行動系列の研究、モデル開発・検証 | 所属、研究計画、利用許諾などの審査がある |
| 商用 | 高頻度GPS、人流推計、来訪、OD、屋内行動 | 事業運用、詳細分析、システム連携 | 個別見積もりや用途制限がある |

## 公開データと閲覧サービス

| データ | 主な内容 | 読みどころ |
| --- | --- | --- |
| 国交省「全国の人流オープンデータ」 | 1kmメッシュ滞在人口、市区町村別の発地属性 | 軌跡ではなく、月・平休日・昼夜などで集計された人口である |
| RESAS LocationMind xPop | 250mメッシュ（政令市・東京23区は125m）の滞留・通過人口 | 閲覧とデータ取得・再利用を区別する。CSV取得条件は今回未確認 |
| パーソントリップ調査 | 移動目的、交通手段、出発地・到着地 | GPSより位置は粗いが、移動目的と行動連鎖を扱える |
| 全国都市交通特性調査 | 複数都市の平日・休日の移動特性 | 都市間の行動特性比較に向く |
| 国勢調査の通勤・通学OD | 常住地と従業地・通学地、昼夜間人口 | 定常的な居住地―勤務地構造を扱える |
| 国土数値情報「駅別乗降客数」 | 年度別に整理された、駅ごとの1日あたり乗降客数 | 駅勢圏の基礎指標になるが、事業者ごとの算出方法を確認する |
| FF-Data | 訪日外国人の都道府県間流動 | 国籍や交通手段を含む広域のインバウンドODに向く |

G空間情報センターには、実証事業で作られた地域限定の高精細データもある。全国一律のデータだけでなく、対象地域の公開データを検索する価値がある。

### 公開日・更新日と、データが表す期間は別

国土交通省の公開案内が示す全国人流データの対象期間は、2019年1月〜2021年12月である。2026年にページを閲覧・取得しても、2026年の人の動きを表すデータにはならない。コロナ禍前後の比較など、対象期間に合う問いで利用する。

提供ページの更新日、データの観測・集計期間、取得日を分けて確認する。現時点の商圏や来訪状況を知りたい場合は、必要な期間を含むデータかを先に確かめる。今回、配布ファイルの内容や算出方法の再検証は行っていない。

### RESASの色と集計値を読む

2026年2月の公式説明資料では、表示範囲内の値で色を決めるため、縮尺を変えると同じメッシュの色も変わるとしている。色の変化だけで人口が増減したと判断しない。

滞留人口の任意地域選択では、含まれるメッシュの総数を合計し、面積による按分はしないと説明されている。描いた境界にぴったり一致する区域内人口とは区別する。表示できる期間やCSV取得・再利用条件は、利用時に確認する。

### 駅別乗降客数の単位を読む

国土数値情報の2023年度版の定義は「人／日」である。年度別の項目があっても、年間の合計人数ではない。データの整備年度と元の統計の年度も分けて確認する。一部の駅は非公開のため、欠けた値を利用者0人として扱わない。今回確認した版の利用条件はCC BY 4.0である。

## 研究申請型データ

東京大学空間情報科学研究センター（CSIS）のJoRASは、共同研究の承認を経て利用する仕組みである。概要ページは大学・研究機関に所属する研究者を申請対象とし、研究期間は原則として承認年度内、継続は再申請、年次の研究報告と成果公表時の謝辞を求めている。アカウント登録だけで全データを自由に利用できるわけではない。

| データ | 確認した性質・条件 |
| --- | --- |
| 実人流データ（ジオテクノロジーズ提供） | GPSに基づくデータ。共同研究申請に加え、利用許諾申請書の提出が必要 |
| Pseudo-PFLOW | 公開統計と交通調査を組み合わせた合成の人流。実在する個人の観測軌跡ではない。利用する地域・版ごとの説明を確認 |

JoRASには2026年9月9日付で「東京都、2026年5月」の実人流データ追加が掲載されている。ただし、その詳細ページの人数等の説明には「2023年5月」と残る箇所がある。掲載名と説明の時点が一致しないため、その人数を2026年版の規模として引用せず、利用時に仕様書や提供元へ確認する。

JoRASの英語FAQは、データや派生物を外部の生成AIサービスへアップロードすることを原則認めず、例外には事前承認などの条件があると説明している。研究利用の許可と外部サービスへの送信許可を同一視せず、利用データごとの条件を確認する。

今回、申請・データ取得・精度検証は行っていない。合成データの生成年や版番号を、実際の人々を観測した年月として扱わない。

## 商用データの見方

代表的な提供形態には、GPS由来の高精細な流動・来訪データ、携帯電話ネットワーク由来の人口推計、アプリSDKやビーコンを使った施設内外の行動データがある。

例として、Agoop、KDDI Location Data、NTTドコモのモバイル空間統計、LocationMind xPop、Geo-People、unerryのBeacon Bankなどがある。名称や仕様だけで比較せず、次を確認する。

- 位置情報の取得方式と対象母集団
- 最小の空間・時間粒度
- 位置点、軌跡、滞在、来訪、ODのどこまで提供されるか
- 観測サンプルと拡大推計の方法
- CSV、API、ダッシュボードなどの提供形態
- 過去データ、更新頻度、利用可能な属性
- 個人情報保護、秘匿処理、二次利用の条件

## 目的から選ぶ

- 地域の基礎人口や商圏を比較するなら、国勢調査や集計済みメッシュから始める。
- 移動目的や交通手段を見るなら、パーソントリップ調査を使う。
- 時系列の行動や経路を学習対象にするなら、研究申請型または商用の軌跡データを検討する。
- 屋内や店舗内の来訪を扱うなら、GPSだけでなくビーコンや施設形状を使うサービスを確認する。
- システムへ継続的に組み込むなら、API、更新頻度、契約上の再利用範囲を先に確認する。
