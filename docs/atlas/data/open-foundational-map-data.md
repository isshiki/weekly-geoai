# オープンな基盤地図データと共同整備

建物・道路・施設・住所などの基礎データを共通基盤として整備し、その上に業務固有の情報を重ねる考え方である。Overture Maps FoundationのWill Mortensonは2026年9月24日の論考で、行政と企業が基盤データを共同で整備・利用するよう提案した。

## 論考が挙げる論点

- データの信頼性を作成主体だけで判断せず、精度・鮮度・相互運用性・利用目的への適合から評価する。
- 部署ごとの重複調達や、他機関への共有を妨げる条件を見直す。
- 共通の基盤を共同で更新し、各組織は自分たちの業務に必要な情報へ投資する。

これはOverture側の提言であり、すべての行政データより民間データの方が優れているという比較結果ではない。また、個別データのライセンスや帰属表示の条件がなくなることを意味しない。

## 利用側で残したい情報

以下はAtlasの実務上の整理である。共通データを使う場合も、取得版、対象範囲、出所、更新時点、独自に加工した内容を残す。同じ基盤を使っていても、取得時点や施設分類が違えば分析結果は一致しない。
