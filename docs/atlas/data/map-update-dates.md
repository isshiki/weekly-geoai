# 地図の提供日と現況の時点

地図の更新日は、その地域を観測した日や、すべての地物が最新になった日と一致するとは限らない。利用時は、提供開始日、原資料の時点、変更対象を区別する。

## 国土地理院の更新一覧

電子地形図25000・数値地図（国土基本情報）の公式一覧は、図郭ごとの更新日をPDF・CSVでも提供する。表中の更新日はデータの提供開始日であり、その日の現況を必ずしも反映しないと明記されている。

2026年10月1日更新のページには、9月30日の居住地名・自然地名・公共施設の地名情報、9月25日の和賀岳地区の登山道、9月20日のくま川鉄道の駅移転・駅名変更などが記載されている。データ全体が一斉に更新されたと解釈せず、対象メッシュと更新内容を照合する。
