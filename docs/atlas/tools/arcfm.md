# ArcFM

ArcFMは電力・通信などの設備をGIS上で管理するソリューションである。ArcGIS Utility Networkを基盤に、電柱・電線・変圧器などの設計・保守・運用情報を統合する。

## 国内提供とシステム連携

NECとシュナイダーエレクトリックは2026年9月30日、NECが日本初のSIパートナー認定を取得し、国内提供を開始したと発表した。NECは国内事業者の固有の要件に合わせたシステム構築を担う。高度配電管理システム（ADMS）との連携にも対応する。

発表にある500社以上という採用数は世界のユーティリティ事業者の数であり、日本国内の導入実績ではない。設備を地図に表示する機能に加え、設計から運用まで同じ設備情報をつなぐことが主題である。
