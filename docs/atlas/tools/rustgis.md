# RustGIS

RustGISは、地図の作成、編集、解析、出力を行うRust製の無料・オープンソースGISアプリである。2026年10月12日に初版v0.1.0を公開した。Windows・macOS・Linuxで動き、WebAssemblyを使うブラウザー版も提供する。

## 使いどころと必要な準備

手元の地理空間データを読み込み、地図の色分けや解析、レイアウト・PDF出力を行う。画面操作に加え、CLI（コマンドライン）から操作をスクリプト化できる。AIアシスタントは選択したモデルで同じアプリのコマンドを実行する。

| 利用方法 | 確認する条件 |
| --- | --- |
| デスクトップ | OSに合うアプリと入力データを用意する |
| ブラウザー | WebGPUまたはWebGL2に対応した環境を使い、形式ごとの対応を確認する |
| AIアシスタント | 選択するプロバイダー・モデルの接続設定と、送信する情報を確認する |
| 拡張・自動化 | CLIのコマンドやWebAssemblyプラグインを利用する |

## 読込・SQL・外部AIの連携

2026年10月13日公開のv0.2.0では、GeoPackage・GeoParquet・FlatGeobufなどを直接開き、大きなファイルは表示範囲に応じて段階的に読む。ZIP形式のShapefileも含め、ブラウザー版の対応形式が拡張された。初版の導入資料にあった制限と、現行版の対応を混同しない。

DuckDB SpatialでのSQL実行・DuckDBファイルの読込と、GDALのogr2ogrを使う形式の読込は、対応する外部ツールの導入が前提になる。MCPサーバーからAIエージェントがRustGISのコマンドを実行し、地図を作れる。GeoPackage・GeoParquetなどへの書き出しも加わった。

## 座標系を保ち、道路に沿う到達範囲を調べる

v0.8.0では、読込時に一律に緯度経度へ変換する方式から、レイヤーが持つ座標参照系（CRS）を保存・描画・編集・解析・書出しで保持する方式へ変わった。対応する解析は元の投影座標系を使える。ただし、どのCRSでも地上の距離を正しく測れるという意味ではなく、対象地域と処理に合う座標系を確認する。

| 機能 | 使いどころと出力 |
| --- | --- |
| Service Area | 施設から指定コスト以内で到達できる道路の線を取り出す。面の商圏を自動生成する機能とは区別する |
| OD Cost Matrix | 複数の出発地と目的地の組み合わせについて、ネットワーク上のコストと距離を表にする |

現行公式ガイドでは、頂点が接する線をネットワークとして結び、各線を双方向に通行できるものとして扱う。費用属性は線の長さへ掛ける仕組みである。一方通行や交通規制、所要時間を自動的に反映すると解釈しない。ネットワーク探索は楕円体上の距離に基づき、すべての計算が元の平面座標系だけで完結するわけではない。接続していない地点の組み合わせは行列に行が作られないため、欠けた行を移動コスト0と扱わない。

## 現地で記録し、元の地図へ戻す

v0.7.0（2026年11月16日公開）はAndroid・iOSアプリを追加した。たとえば設備点検なら、事前に背景地図を含む地図を端末へ持ち出し、現地で設備の位置・状態・写真を記録し、帰ってから元のプロジェクトへ編集を取り込む、という使い方ができる。これは機能から示した利用例で、点検業務の実証結果ではない。

背景地図にはMBTilesやPMTilesを使い、点・線・面の取得、入力規則に沿うフォーム、写真添付、画面を消した状態での軌跡記録に対応する。Bring Backは現地の編集と写真を元のプロジェクトへ統合する機能である。必要な範囲の地図を事前に用意し、測位のずれや編集の反映を確認する。端末間の共同編集・競合解消の挙動は今回未検証。

## 地形表示と配布用の地図

地形の陰影、水面の平坦化、地形を箱状に切り出す表現に加え、レイアウトを位置情報付きGeoPDFへ出力できる。PDFにはフォントと地図レイヤーも保持する。CityGML 1.0〜3.0、LERC圧縮GeoTIFF、Zarrの部分読込も案内されている。見栄えを整える機能と、元データの位置・標高の正確さは分けて確認する。

## データとAIの関係

開発元は、選択したAIモデルへ送る場合を除き、データは利用者のマシンに保持すると説明する。クラウドのAIモデルへの送信とローカルのGIS処理を分ける。初版・v0.2.0に加え、v0.7.0の公式発表を確認したもので、アプリの実行や性能比較は行っていない。

v0.8.0のAIアシスタントは、添付画像や`view_map`で取得した地図・レイアウトの画像も参照できる。現行ガイドによると、送信内容にはメッセージ、レイヤー名・項目・範囲、読み取った行などの結果、添付画像や地図画像が含まれる。画像を見られることと、距離や座標を正確に検証できることは別である。今回も実操作・通信内容の監査は行っていない。
