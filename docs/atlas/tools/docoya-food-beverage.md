# DOCOYAフード&ビバレッジ

DOCOYAフード&ビバレッジは、飲食店データベース「InsiteStream」と商圏分析ツール「DOCOYA」を組み合わせ、出店計画、既存店分析、競合分析、営業先開拓を支援するパッケージである。

## 確認したポイント

- 個人店を含む全国約91万件の飲食店データを標準搭載し、ジャンル、名称、住所、座席数、評価、最寄り駅、決済方法などを地図上で分析できる。
- 移動商圏や顧客商圏、人流データ、競合飲食店の密度と業態を重ね、出店候補地を評価する。
- 既存店では人口構成、人流の変化、競合の増減を可視化し、営業時間や販促などの見直しに利用する。
- 食品メーカーや卸などは、エリア別の飲食店数と業態分布から営業重点エリアと訪問先候補を抽出できる。
- SaaS型クラウドサービスのほか、要件に応じたオンプレミス構築とタブレット利用にも対応する。
