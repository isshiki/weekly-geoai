# OH3 今昔マップビューア

OH3 今昔マップビューアは、同じ場所の時代ごとの地形図を切り替えて閲覧する軽量なWebビューアである。

## 比較できる内容

- 年代スライダーと自動再生で、明治から平成までの地図を順に表示する。
- 現在の地図を半透明で重ね、道路・駅と過去の地形との位置関係を確認する。
- 2026年9月20日の確認時点で59地域に対応し、無料・ログイン不要と案内されている。

## 地図の出典と範囲

過去の地図は谷謙二氏の「今昔マップ on the web」のタイルを利用し、現在の地図・写真は地理院タイルを使う。地域ごとに4〜10期の地図があり、最後の2つは現在の地図と写真である。

主要都市周辺が対象で、範囲外やズーム8未満では古地図が表示されない。全国の全地点・全時代を網羅するものではない。

[ビューアを開く](https://oh3lab.jp/oh3/konjaku-lite.html)
