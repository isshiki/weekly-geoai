# GeoNode

GeoNodeは、地理空間データや関連資料を検索・共有するオープンソースのポータルである。データに説明や利用権限を付け、組織や利用者が見つけて使える状態にする。公開・運用にはGeoNode環境と管理者による設定が必要となる。

## 地図以外の資料も整理する

5.1.0の紹介では、座標を持たないCSVも検索・ダウンロードできる資源として登録できる。文書は手動指定やEXIFから位置を付け、地図上の点からプレビューする。多言語メタデータにも対応し、資料の内容を利用者へ説明する手段を広げている。

## データの置き場所と利用権限

| 取り込み方法 | 確認する点 |
| --- | --- |
| リモートCOG・FlatGeobuf | URLで参照し、HTTP Rangeで必要な部分を読む。元の配信元への依存が残る |
| Excel | XLSX入出力に対応。取り込みは管理者による有効化が必要 |
| 文書・表 | 検索、閲覧、ダウンロードなどの権限を設定する |

リモート資源の登録は既定で管理者向けである。FlatGeobufにはRange非対応時の代替処理もあり、どの配信元でも同じ取得量・性能になるとは限らない。データを置くこと、検索できること、ダウンロードを許可することを分けて設計する。

2026年10月13日の開発元記事を確認した。ここでの機能説明は導入・実行試験や速度比較の結果ではない。
