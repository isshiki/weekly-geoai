# ArcGIS Solutions

ArcGIS Solutionsは、業種・業務の目的に合わせたArcGISの構成を提供する。個々の解析機能に加え、業務の入力・管理・共有までを組み合わせる。

## 2026年9月版の新規構成

9月29日の発表では次の5種類を追加した。

| 構成 | 目的 |
| --- | --- |
| Beach Analysis | 防衛機関向けの海岸特性分析と地理空間情報の共有 |
| Electric Joint Use Permitting | 電柱への設備取り付け申請・許可と状況管理 |
| Market Planning and Development | 顧客・競合・人口統計・市況による拠点分析 |
| Solar Panel Inspections | 太陽光パネル点検の範囲・担当・結果の管理 |
| Virtual Damage Reporting | 災害後の画像とGeoAIによる遠隔被害評価・推計の共有 |

通信網や犯罪分析などの既存構成にも改良を加えた。また、Electric Joint Useなど5構成はMature段階へ移行し、ヘルプはArchived helpで参照する。新しいElectric Joint Use Permittingと、Matureへ移ったElectric Joint Useを混同しない。利用環境・必要な製品構成と評価精度は個別に確認する。
