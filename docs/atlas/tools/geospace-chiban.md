# GEOSPACE 地番地図とちばんAPIワイド

NTTインフラネットのGEOSPACE 地番地図は、公図や自治体の地番図などをもとに地番・筆界をベクトルデータとして提供するサービスである。ちばんAPIワイドでは、地番と住所・緯度経度の相互検索や、用途地域・ハザード情報などを組み合わせた利用を案内している。

## 地番データと道路幅員を組み合わせる

2026年9月25日の発表では、地番・筆界データの提供エリアを9道府県の10市町で拡大した。これは今回の追加範囲であり、サービス全体の提供範囲ではない。対象市町名は本文に掲載せず、個別問い合わせとしている。

同時に、ちばんAPIワイドで全国対応の道路幅員データの提供を開始した。幅員データは同社のGEOSPACE 電子地図データをもとに生成する。不動産調査などで、地番と周辺道路の情報を組み合わせる用途を示している。

| 情報 | 分析時に確認する点 |
| --- | --- |
| 地番・筆界 | 対象自治体、元資料、更新時点 |
| 道路幅員 | 生成元の地図、幅員の定義、精度、対象道路 |
| 用途地域・ハザード | 参照元と基準日、地番との対応 |

発表は「高精度」「全国対応」としているが、数値による精度評価や更新間隔は示していない。現地実測値や、すべての道路を同じ精度で収録する保証とは読み替えない。
