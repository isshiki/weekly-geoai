# LocateXT：文書から位置を抽出する

LocateXTは、Word・PDF・HTML・メールなどに埋まった座標や日時を抽出し、地図上の点へ変えるArcGIS Proの機能である。生成AIによる文脈理解ではなく、地名辞書・キーワード・座標や日付の形式を使う。

## 利用条件と日本語文書

Pro 3.5からStandard以上のコア機能となり、国内サポート対象にもなった。日本語では単語区切りをオフにし、日本語の設定へ置き換える。全角数字の座標は非対応なので、入力前の変換が必要である。

ESRIジャパンの10月26日の記事は海難事故の2文書から地点を抽出する手順を示す。抽出後は元の文章、座標、日時を照合する。文書から位置を拾う処理と、住所を地図サービスで照合する[ジオコーディング](arcgis-geocoding.md)は別の段階である。Atlasではアプリ操作を再実行していない。
