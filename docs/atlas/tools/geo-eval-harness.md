# geo-eval-harness

geo-eval-harnessは、衛星画像などを扱うAIモデルを共通の条件で比べるための評価ツールである。地図を対話で操作するアプリではなく、モデルを選ぶ研究者・分析担当者向けのPython環境で使う。Python 3.12以上と、評価用データ・計算環境の準備が必要になる。

## 使いどころ

例えば建物の輪郭を抽出するモデルを選ぶなら、同じデータと学習条件で精度・計算量を比較する。公開コードは分類・セグメンテーションに加え、位置エンコーダーの評価も案内する。コードのMITライセンスと、各モデル・データセットの利用条件は別に確認する。

## 順位と不確実性を一緒に読む

2026年11月25日投稿の論文要旨では、地理空間・一般画像を含む100モデルを、分類6件・セグメンテーション14件のデータセットで比較している。上位10分類モデルのペア比較では、各データセットで95%信頼区間が重なる割合が73%だった。重なりは「完全に同じ性能」の証明ではなく、小さな順位差を確実な優劣として扱いにくいことを示す。

SpaceNet2でエンコーダーを固定した比較では、mIoUの差が0.9ポイントでも計算量が5.9倍異なる例を報告している。自分の用途では、精度だけでなく処理時間・計算費用と検証地域を合わせて選ぶ。
