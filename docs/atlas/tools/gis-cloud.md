# GIS CloudのAIによる現場調査支援

GIS Cloudは地図と現場のデータ収集を扱うサービスである。PSSの2026年10月21日の記事は、Ask AIで調査フォームを作り、iPhoneのMobile Data Collectionで写真・音声から入力する道路標識調査を紹介する。利用にはGIS Cloudの環境と対応アプリが必要で、この記事だけでは契約プランや料金は確定しない。

## AIに任せた作業と試験調査で見る点

| 作者が試したこと | 確認すること |
| --- | --- |
| 会話からフォームと条件付き表示を作る | 必要な項目・選択肢が調査目的に合うか |
| 写真から状態・備考を入力する | 見えない情報を推測で埋めていないか |
| 音声の「2.5m」を250cmへ換算する | 保存する単位と数値が一致するか |
| 写真の後に音声で補足する | 先に入力された備考を上書きしないか |
| 調査者・調査日時を設定する | 前回の値の引き継ぎと、今回の記録を区別できるか |

作者の試行では標識IDの自動連番は未実装と回答され、手動入力した。AI入力は通信が必要で、およそ5秒は作者の体感であり、応答時間の保証ではない。写真処理の待ち時間に手入力し、その後に音声を補う手順も紹介する。

## 使う前に小さく試す

フォームが作れた段階で本調査へ進まず、数件を収集して値・単位・日時・上書きの挙動を確かめる。この記事は作者の実地試行で、画像認識の精度比較やAtlasでの再実行ではない。
