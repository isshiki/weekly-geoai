# Mapbox Traffic

Mapbox Trafficは、交通状況を経路探索や到着予定時刻（ETA）の計算に利用するサービスである。

## Traffic 2.0

2026年9月16日の発表では、Maps SDK、Navigation SDK、Directions API、Matrix API、Traffic Dataで提供開始したと説明している。

| 更新点 | 発表内容 |
| --- | --- |
| 分岐と直進 | 高速道路などで、分岐側の渋滞と直進側の交通を区別する |
| 予測 | 最大2.5時間先の交通を予測する |
| 更新遅延 | 交通状況によっては1分未満で速度情報を反映する |

既存利用者にはサービス側で改善が適用される。Mapboxは98%の行程で正確なETAを生成するとしているが、記事には許容誤差などの評価条件が示されていないため、独立した精度比較には使わない。
