# Geospect

Geospectは、地理空間オープンデータの検索と地図上のプレビューを行うサービスである。2026年10月1日の開発者記事は、50以上の提供元から4,500件以上を掲載すると説明する。データセットの数え方は独自整理で、提供元の件数とは一致しない場合がある。

## 調べる段階で使う

| 機能 | 確認できる内容 |
| --- | --- |
| カタログ検索 | 概要・属性項目・形式・公式リンク |
| 地図プレビュー | 分布、色分け・凡例、個別地物の属性 |
| タイル配信 | QGIS等での重ね合わせ。Style JSON・TileJSONも提供 |

主用途は探索・検証であり、本番向け配信サービスではない。全国規模のデータが中心で、自治体独自データの掲載は限定的である。2D表示、位置情報のないレコードの除外、形状の簡略化・間引き・修復があるため、表示件数や形状を原本と同一とみなさず、出典・加工情報を確認する。
