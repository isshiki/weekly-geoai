# ゼンリン まっちず

まっちずは、ゼンリンが2026年10月1日に提供を開始した不動産BtoBマッチングサービスである。

## 買い手の条件から商談を始める

買い手が希望エリア・予算・用途・面積などの購入ニーズを公開し、売り手が合う物件について直接商談を提案する。売却物件の広告を起点とする方式に対し、購入ニーズを起点に相手を探す構成である。

公式発表は買い手の物件探しと売り手の売却先候補探しの効率化を狙うと説明する。成約率や効率化の実測値、AIによるマッチング機能は今回の発表からは確認していない。
