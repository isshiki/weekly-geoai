# OpenPOI API

OpenPOI APIは、Overture MapsとJapan Food Facilitiesの食品営業許可・届出データを統合した、日本の施設検索APIである。2026年10月2日の公式説明は3,372,487件を案内する。収録件数は、営業中の店舗数や位置精度の検証値ではない。

## 検索と入力補完の違い

| 接続先 | 条件・用途 |
| --- | --- |
| `/v1/search` | 複数語はOR。最大200件。bboxまたは中心座標と半径で絞り、中心指定時は近い順 |
| `/v1/suggest` | 複数語はAND。表記ゆれ・重複を処理し、表示範囲で0件なら全国へ拡大 |
| `/mcp` | 施設検索とデータセット情報をAIクライアントへ公開 |

APIキーは不要である。文書上の制限は利用者別でなくAPI全体で定常200 req/s・バースト600 req/sで、超過時は429を返す。検索の返却上限を地域全体の件数とみなさない。

## 保存と品質を分けて確認する

公式文書は商用利用と検索結果の保存を認め、`licenses`と`attributions`も配列のまま保持するよう求める。表示・再配布・加工公開では適用条件が異なるため、出典ページと各データの条件を参照する。

カテゴリ不明は約54.6％と記載され、カテゴリ検索で拾えないレコードがある。確認時点のOverture由来データは2026-08-19.0で、元データの最新版とAPIの取り込み版を区別する。公式文書には利用規約・プライバシー・サポートへの案内がある。今回、検索APIの実行や位置・営業状態の実測検証は行っていない。
