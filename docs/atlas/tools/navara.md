# Navara

Navaraは、地形・写真・3D都市モデルなどをブラウザーの地球儀上で組み合わせる地図エンジンである。完成済みのGISアプリではなく、Webアプリに組み込んで使う。地理データの処理はRust／WebAssembly、描画は現在Three.jsが担い、描画部分を交換できる設計を採る。

公式リポジトリはMapLibre組織で公開され、MITまたはApache-2.0を選べる。アプリで使う写真・標高などのデータの利用条件は別途確認する。

## 地形と写真を重ねる例

2026年10月24日のQiita記事は、Node.js・TypeScript・Viteで箱根・芦ノ湖周辺を表示する例を紹介する。地形と写真の表示切り替え、真上・斜めの視点変更を実装している。

| 材料 | 役割と確認点 |
| --- | --- |
| 国土地理院のPNG標高タイル | RGB値から標高を復号して起伏を作る。通常の白黒画像として読まない |
| 空中写真タイル | 地形の表面へ重ねる。写真の細かさが標高の細かさを増やすわけではない |
| WebAssembly・Workerを含む生成物 | 公開時にHTMLだけでなく一式を配信する |

記事は独自GeoTIFFの直接読み込みを実装したものではない。別データへ替える際は形式、座標系、標高単位、欠損値をそろえる。ビルド成功は著者の報告で、Atlasではコードやブラウザー表示を再検証していない。
