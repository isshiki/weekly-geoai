# Google MapsのAsk MapsとImmersive Navigation

Google Mapsは、Geminiを用いる対話型の場所探しと、3D表示を使う運転案内を提供する。開発者向けのAPIやMCPの提供とは区別する。

## 2026年3月の発表

| 機能 | 役割 | 発表時の提供地域 |
| --- | --- | --- |
| Ask Maps | 複数条件の場所探しに対話で答え、候補を地図表示。保存・予約・経路案内へつなぐ | 米国・インドのAndroid／iOSから |
| Immersive Navigation | 建物・道路の3D表示、車線、代替ルート、駐車場所・入口の案内 | 米国から順次 |

GoogleはAsk Mapsで3億カ所超の場所情報と5億人超の投稿者によるレビューなどを活用すると説明する。規模は同社公表値である。この記事は2026年3月12日公開であり、9月の新発表ではない。表は発表時の範囲であり、9月29日現在の全地域の提供状況を確認したものではない。

## 店舗側は元情報と重要な翻訳を整える

イクシアスの2026年3月3日の資料案内は、AIの口コミ要約を直接編集することと、元になる店舗情報を整備することを区別する。料金、アレルギー、安全に関わる情報は、自動翻訳だけに任せず人が確認した多言語表記を用意するという提案である。

資料案内ページを確認したもので、配布資料本体やGoogleの全地域での提供状況は確認していない。10月の新機能発表としては扱わない。

## 紹介投稿の日付と機能の発表日を分ける

2026年11月1日に確認したGoogle公式資料では、2億5,000万カ所の情報に基づくGeminiの場所提案・レビュー要約は2024年10月31日に発表されている。2026年3月12日のAsk Maps発表は3億カ所超と説明する。規模の数字は各発表時点のもので、全地点がリアルタイムに検証されるという保証ではない。

今回提供されたX投稿本文は取得できず、投稿者の紹介日を新機能の公開日とは扱わない。上記は公式発表で確認できた背景であり、投稿内容や現在の日本での提供範囲を確認したものではない。
