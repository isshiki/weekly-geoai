# SateAIs

SateAIsはスペースシフトの衛星データ解析サービスである。2026年9月29日の発表では、Webコンソールのマップ解析を9月25日から提供していると説明する。

## 地図とチャットによる解析

利用者が地図上で範囲・種類・日付を指定する方法と、AIアシスタントへ自然文で依頼する方法がある。AIが提案した範囲・条件は、利用者が確認・承認してから実行し、結果を地図で確認する。

| 解析 | 対象 |
| --- | --- |
| 船舶・油膜検知 | 海域の船や油の範囲 |
| 新規・消失建物検知 | 期間中の建物の増減 |
| 時系列変化検知 | 同じ場所の変化 |

5種類の解析にはSentinel-1のSARデータを使用する。観測日・頻度は衛星の運用条件に依存する。登録時に500クレジットを無償付与し、解析面積に応じた消費量を実行前に表示するという発表時の条件である。ブラウザーで実行できることと、個々の検知精度は別に確認する。今回はサービスの実行検証は行っていない。
