# Mapbox WebMCPによるWeb地図のAI操作

Mapbox WebMCP plugin for GL JSは、Webサイトの地図にAI向けの操作口を付けるプラグインである。開発者が組み込むと、対応するブラウザエージェントが地図を動かし、条件に合う地点を強調できる。利用者がどのWeb地図でも自動的に操作できる機能ではない。

## できることと対象範囲

| 操作 | 例・条件 |
| --- | --- |
| 表示を変える | 地図の移動、レイヤーの絞り込み、スタイル変更 |
| 地点を調べる | 読み込み済みタイルや画面内の地物を検索。全データセットの検索ではない |
| 情報を重ねる | マーカーやGeoJSONを追加し、結果の状態をJSONで受け取る |

例えば、地図が持つ評価属性でカフェを絞り込める。ただし、評価や店舗情報そのものをプラグインが新たに収集するわけではない。開発者は公開するツールを選べる。標準構成は7ツール・28操作で、ページ内で動き、専用MCPサーバーの設置は不要である。

## 利用前に確認すること

2026年11月19日発表の公開プレビューで、Mapbox GL JS 3.35.0以降が必要。WebMCPは策定中の標準で、公式記事はChromeの試験設定またはオリジントライアルを案内している。対応しないブラウザでは操作ツールを登録せず、通常の地図として動く。公開プレビューを、地図サービス全体の無料・無制限提供と読み替えない。

これはWebページ内の地図を操作する接続である。ChatGPT向けプラグインや[Mapbox CLI](mapbox-cli.md)の端末操作とは入口が異なる。公式記事を確認した整理であり、接続や操作は試していない。
