# Kodawari

Kodawariは、自分が重視する条件で日本の住みやすい地域を探すブラウザー向け地図サービスである。地図表示にはJavaScriptが必要である。

## 公式サイトが案内する機能

日本全国を100m四方ごとに色分けし、駅・スーパー・学校・公園・カフェ・古着屋・静かさ・地価などへ利用者の優先度を反映する。移動手段は徒歩・自転車・車を案内している。

## 評価を見るときの確認点

100mは紹介文に記載された表示単位であり、元データの位置精度や評価精度を示すものではない。優先度を変えて候補地域を比較する入口として読めるが、評価式、データの出典・更新頻度、所要時間の算出方法、料金・アカウント条件は今回確認できていない。

2026-10-06時点で公式紹介文のみ確認した。操作画面の検証は未実施で、公開日も確認できなかった。
