# Kodawari

Kodawariは、自分が重視する条件で日本の住みやすい地域を探すブラウザー向け地図サービスである。地図表示にはJavaScriptが必要である。

## 公式サイトが案内する機能

日本全国を100m四方ごとに色分けし、駅・スーパー・学校・公園・カフェ・古着屋・静かさ・地価などへ利用者の優先度を反映する。操作画面では徒歩・自転車・車・電車とバスを選択できる。

## スコアと出典の読み方

2026-10-06に操作画面の「Kodawariについて」と出典欄を確認した。運営者の説明では、移動手段ごとに到達できる施設数を数え、利用者が選ぶ条件から0〜100のスコアを作る。条件ごとの充足数で加点が頭打ちになる設定があり、重みや除外条件も結果へ影響する。

施設にはFoursquare Open Source PlacesとOpenStreetMap、地域条件には国勢調査などを使うと説明している。データ更新の目安は月1回程度だが、元データの時点は異なる。確認時のフッターには国勢調査2020、Foursquare 2026-09-15、OSM 2026-10-01などが表示されていた。

100mは表示・集計単位であり、元データの位置精度や評価精度を示すものではない。所得などにはサイト独自の推計も含まれる。スコアは好みとデータに基づく比較の入口として使い、公式説明があることと計算の正確さを検証したことを分ける。

今回確認したのは画面上の説明と出典であり、算式全体の再現、所要時間・順位・施設網羅性の精度検証は未実施。公開日や料金・アカウント条件も確認していない。
