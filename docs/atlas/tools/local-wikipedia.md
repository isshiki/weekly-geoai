# Local Wikipedia

Local Wikipediaは、現在地や指定地点の近くにある場所のWikipedia記事を集めるWebサイトである。地名・ランドマークの入力またはブラウザの位置情報で検索し、周辺の歴史や施設を知る入口にできる。

## 近くの情報を地図から探す

2026年10月26日のGIGAZINEレビューでは、半径1.5マイル（約2.4km）の円と、距離順の記事一覧を表示する。「徒歩30分」は紹介上の目安であり、道路・橋・通行可否を計算した等時線ではない。

レビュー時点の対応は英語など9言語で日本語は含まれない。記事の少ない地域や言語では結果も少なく、施設を網羅するPOIデータベースではない。公式画面の検索案内とレビュー本文を確認したが、位置情報の送信や検索操作は実行していない。
