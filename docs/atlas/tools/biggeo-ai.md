# BigGeo AI

BigGeo AIは、自然言語の質問をBigGeo側の空間処理につなぎ、結果をAIアシスタントへ返すサービスである。同社は2026年9月22日、ChatGPTとClaude内で利用可能になったと発表した。

## データと処理の分担

| 段階 | 同社の説明 |
| --- | --- |
| 質問 | 利用者が自然言語で場所や出店などについて質問する |
| 計算 | BigGeoが地理的範囲を解決し、利用者のライブラリ内のデータを照会する |
| 応答 | 元データをモデルへ渡さず計算結果を返す |

ライブラリには追加可能な1,000以上のオープンデータセット、自社アップロード、ライセンス済みデータを利用できるとする。すべての質問に必要なデータが標準で揃うという意味ではない。

## 確認する点

- 質問をどう地域・条件・集計単位へ変換したかを確認できるか。
- 元データの基準日、網羅性、利用権限が分析目的に合うか。
- 返される集計結果にも機微な情報が含まれないか。

処理速度とデータ保護は企業発表上の説明で、こちらで接続・性能・契約条件を検証したものではない。元レコードを返さない設計だけで、あらゆる情報漏えいの可能性がなくなるとは判断しない。
