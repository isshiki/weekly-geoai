# ArcGIS StoryMaps

ArcGIS StoryMapsは、地図と文章・画像などを組み合わせて場所に関する情報を伝えるツールである。

## Map tourのカスタム背景地図

ツアーブロックの背景地図選択で「Browse more maps」を使い、自分や組織などのWebマップを指定できる。2026年9月15日の記事は、この機能の活用方法を紹介している。

- Webマップの初期表示で有効な地物レイヤーを使い、境界や主題情報を補う。
- Sketchレイヤーで経路や注記、Mediaレイヤーで画像を重ねる。
- Vector Tile Style Editorで配色、ラベル、表示スケールを調整する。

ツアー内では地物ポップアップを利用できない。背景地図に置く情報は、ツアー本文や写真との関係を考えて選ぶ。

## AIアシスタントによるテーマ生成

2026年9月18日の解説は、文章・参考画像から配色やフォントの方向性を作り、テーマビルダーで調整する方法を示す。利用にはArcGIS Online管理者の設定が必要である。

1. Generate themeで説明文や参考画像を指定する。HEXカラーコードも手掛かりになる。
2. 生成後に配色・フォント・背景地図を編集する。
3. 文字の読みやすさとコントラストの警告を確認する。

生成結果は編集の出発点として扱える。文章と画像の併用を推奨しており、AIの自動選択フォントは29種、手動ではGoogle Fontsを追加できる。

## 読者に伝わる構成と公開範囲

2026年大会の応募ガイドは、想定読者を決め、地図・文章・写真を伝えたい内容に合わせて選ぶことを勧める。地図の数を増やすこと自体を目的にせず、配色や文字をそろえ、結論を裏付ける情報を置く。

作品を公開しても、埋め込んだ地図やレイヤーが非公開なら読者は閲覧できない。共有範囲を構成要素ごとに確認する。応募条件と締切は[10月14日の更新履歴](../../updates/2026-10-14.md)に記録した。
