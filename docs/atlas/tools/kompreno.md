# コンプレノ

コンプレノは、Agoopが提供する、人の移動を動画で可視化し比較・分析するサービスである。施設・観光地や市区町村の人流を使い、出店、都市開発、観光、防災などの検討を支援する。

## 公共交通徒歩圏と交通機関レイヤ

2026年9月14日に追加された公共交通徒歩圏レイヤは、駅・バス停までの道路に沿った徒歩距離を基に、地域を駅圏内、バス停圏内、駅・バス停圏外に分ける。

| 設定・機能 | 内容 |
| --- | --- |
| 表示単位 | 50mまたは125mメッシュ |
| 歩行速度 | 一般80m/分、高齢者等60m/分 |
| 交通機関レイヤ | 全国のバス路線・バス停、鉄道線路・駅 |
| 人流との組み合わせ | バス路線再編や新交通サービスの検討 |

判定は国土交通省の資料を参考にしたAgoop独自のロジックである。道路勾配や信号待ちは考慮せず、データの整備時点によって現況と異なる場合がある。表示は交通施策を検討する参考情報として扱う。
