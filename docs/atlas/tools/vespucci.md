# Vespucci：AndroidでOpenStreetMapを編集する

VespucciはAndroid向けの無料OpenStreetMap（OSM）エディタである。地図を見るだけでなく、現地で確認した地点・道路・建物や属性を編集する用途に使える。Google Playなどから導入でき、オフライン作業にも対応する。

## 編集できるもの

| 対象 | 機能例 |
| --- | --- |
| 地物と属性 | 点・線・面の作成や形状修正、タグ編集 |
| 地物の関係 | リレーション、ルート、右左折制限 |
| 現地確認の補助 | GPS軌跡、位置情報付き写真、Mapillary画像 |
| 入力と点検 | JOSMプリセット、GeoJSONレイヤー、道路名欠落・FIXMEなどの強調 |

GIGAZINEの2026年10月17日の記事は、既存地物の修正と建物の追加を実演する。新製品の発売や、その日に全機能が追加されたというニュースではない。公式サイトは2009年から開発を継続していると説明する。

## 編集と公開を分ける

OSMへの反映にはアカウント認証とアップロードが必要になる。オフラインで編集できることと、通信なしでサーバーへ公開できることは別である。公式ヘルプは変更セットのコメントや情報源を扱う。現地で確認した対象と編集内容を照合し、変更理由が分かる形で残す。

本Atlasではアプリの導入・操作やOSMへの書き込みは行っていない。紹介記事と公式機能表・ヘルプを確認した内容である。
