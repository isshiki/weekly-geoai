# ここから何分？

「ここから何分？」は、登録したカフェ・スーパー・公園などへの徒歩時間を地図と一覧でまとめて確認するWebアプリである。ブラウザーからアカウント登録なしで利用できる。

## 使いどころ

現在地、地図のクリック、住所・駅名・施設名から出発地点を選ぶ。ブランドを登録しておくと、出発地点を変えるたびに近い店舗を探し直す。目的地を一つずつ検索せず、移動先で複数の行き先を比較する使い方である。選択した1件だけ経路を表示する。

## 徒歩時間の読み方

- 店舗・施設と徒歩経路にはOpenStreetMapを使う。徒歩20分以内を対象とし、表示は推計時間である。
- 信号待ち、坂道、混雑、営業時間、工事、建物内の移動は反映しない。データにない道路や施設もある。
- 公園は入口ではなく代表地点までの目安である。「到達地点未確認」を施設が存在しない意味に読まない。
- 住所検索で町丁目の代表地点が選ばれた場合は、必要に応じて地図上で起点を直す。

記事本文に基づく紹介であり、Atlasではアプリの操作や経路計算を検証していない。
