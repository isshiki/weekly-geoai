# yuiseki の GeoAI 研究所

yuiseki の GeoAI 研究所は、地理空間オープンデータで地域の課題を調べた研究レポートを公開するサイトである。「避難所は昼間の人口に対して足りそうか」「交通事故はどこで起きているか」など、身近な問いから地図分析の使い方を学べる。分析ソフトそのものではなく、事例と調査手法を読む入口として使う。

## 読める研究

2026年11月1日のトップページには7件の研究が掲載されている。公開日は未確認で、以下は確認時点の一覧である。

| 題材 | 問い・読みどころ |
| --- | --- |
| 東京23区のアンダーパス | OSMから拾った箇所と国の一覧がどの程度重なるか |
| 東京23区の避難所 | 夜間人口と平日昼間人口で潜在需要の見え方がどう変わるか |
| 秋田県のクマ出没通報 | 場所・件数の予測で何が改善し、何が改善しなかったか |
| 千代田区の交通事故 | 件数・地点・時刻など複数の観点から事故の特徴を読む |
| 東京23区の浸水 | 過去の浸水記録を学習したモデルと洪水浸水想定区域を比較する |
| 台東区の交通事故 | 千代田区と同じ手順で地域の違いを比較できる |
| バス事業者の集中 | 高齢者が住む地域の周辺に何種類の事業者があるか |

各記事から分析の原本と再現手順を確認でき、サイトにはGitHubの分析コード・原本へのリンクがある。まず関心のある地域課題の記事を読み、条件や根拠を知りたくなったら原本へ進む使い方ができる。

## 結果を読むときの確認点

サイトは、データの時点・細かさ・距離の定義・観測できていないものを確認する方針を示している。通常のGISによる集計・比較と、機械学習による予測を分けて読む。

クマの記事では、場所を予測する環境特徴量のモデルは過去の通報密度という比較基準を上回った一方、特徴量を追加しても検証年度の再現率は改善しなかったと報告する。件数やブナの豊凶の予測は単純な比較基準を超えなかった。「AIを使ったか」だけでなく、「何と比べ、どの問いに答えられたか」を確認する例になる。

通報の数はクマの個体数や実際の出没数と同じではない。記事は、地図の色が県内の順位であり確率ではないこと、安全を保証しないこと、将来期間の評価が一部未完了であることも明記している。ここでは公開ページを確認して紹介しており、分析コードの再実行や全研究の独立検証は行っていない。
