# GeoAI（geoai-py）

GeoAIは衛星・航空画像やベクトルデータへAIを適用するPythonパッケージである。地理空間AIという分野全体の呼び名と区別するため、パッケージ名の`geoai-py`を併記する。

## 処理範囲

| 段階 | 主な機能 |
| --- | --- |
| データ準備 | 画像取得、学習用の画像切り出しとラベル作成、Overture Mapsとの連携 |
| 学習・推論 | 分類、物体検出、領域分割、変化検出 |
| 結果の利用 | 地理空間形式への出力、LeafmapやMapLibreによる可視化、QGISプラグイン |

建物抽出や土地被覆分類などに使う。POI商圏分析に特化したライブラリではない。パッケージはMITライセンスだが、利用するモデルやデータの条件はそれぞれ確認する。

## 0.43.1で確認した変更

2026年9月23日時点のPyPI最新版は0.43.1、Python要件は3.12以上である。公開は9月21日20:43 UTC（日本時間9月22日）。以下は公式リリースノートで確認した差分であり、パッケージ全体の機能がこの版で初めて追加されたわけではない。

- 物体検出器の重みを`.safetensors`から読み込み、pickleのデシリアライズを避ける機能。
- `ParkingSpotDetector`への名称修正と、引数なしで読み込める駐車区画検出用の重み公開。
- PCAの主方向計算を`eigh`へ変更するNumPy 2.5互換修正。
- ラスタからベクターへの処理で出力パス引数を修正。

QGISプラグインの版は1.8.1と別に記載されている。推論精度、GPUメモリ、モデルの利用条件は処理ごとに検証する。本ページではインストールや推論の実行は行っていない。
