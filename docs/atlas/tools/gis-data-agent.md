# GIS Data Agent

GIS Data Agentは、地図で矩形範囲を指定し、登録済みの取得元からGISデータを集め、GeoPackageやGeoTIFFへ保存するWebアプリである。rino_yumeが2026年9月28日に紹介したr004が最初の公開版である。

## 自然文による条件整理と実処理

| 担当 | 処理 |
| --- | --- |
| 利用者 | 地図の範囲と出力座標系を指定し、取得計画を確認 |
| Ollamaのqwen3:8b | 自然文を登録済みの取得元IDと抽出方法へ整理 |
| Python | IDを再検証し、ダウンロード・範囲抽出・座標変換・保存を実行 |

LLMにURLや実行コードを自由生成させず、既知の取得元に制限する。MCPからも同じ取得処理を呼び出せる。Dockerとモデルを動かせるNVIDIA GPUが必要である。

## 対応範囲と制限

国土地理院の標高、PLATEAU、静岡県の行政区域・河川、登録した図郭の産総研地質図などを扱う。全国の未知のサイトを自動探索する機能ではない。防災科研の地すべり地形は利用条件を確認するまで初期状態で無効である。

保存する成果を小さな範囲へ絞っても、県・図郭単位の原本ZIPを取得する場合は通信量が同じ割合で減るとは限らない。原本と成果を分け、manifestや処理ログを残す。ローカルLLMでも、データ取得や背景地図の表示には外部通信がある。今回は記事の確認のみで、アプリを実行してはいない。
