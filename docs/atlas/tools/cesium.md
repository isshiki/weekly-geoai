# Cesium

Cesiumは、地球規模の3D地理空間データをタイル化、配信、可視化するための製品・OSS群である。

## 確認したポイント

- 2026年9月には、ベクタータイルがTechnology Previewとして公開された。
- CesiumJS 1.145では、地形や3D Tiles上へのベクターデータのドレープとクリッピングポリゴンが改善された。
- Cesium ionでは、元ソースとタイル化済みアセットを分離して管理する変更が案内された。
