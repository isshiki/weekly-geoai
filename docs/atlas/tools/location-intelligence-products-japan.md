# 日本のロケーションインテリジェンス製品・サービス

日本から利用できるロケーションインテリジェンス製品には、地理・POIデータ、人流・購買データ、クラウド基盤、空間分析、地図API、業務アプリケーションが含まれる。同じ市場名で呼ばれていても、データ販売、API、分析環境、完成した業務ツールでは導入方法が異なる。

## 代表例

| 主な提供価値 | 企業・サービス例 | 提供形態 |
| --- | --- | --- |
| 地図・住所・建物・施設 | ZENRIN | データ、APIなど |
| 国内チェーン店舗 | ロケスマDATA | データ提供 |
| グローバルPOI | Foursquare、SafeGraph | API、データセット |
| 人口・人流 | モバイル空間統計、KDDI Location Analyzer、Agoop | 統計データ、分析サービス |
| 購買 | True Data | データ、分析サービス |

この表は2026年8月時点の代表例であり、製品を一つのレイヤーへ固定するものではない。企業によって複数のデータ、分析、アプリケーションを提供しているため、最新の機能、対象地域、契約条件は各社で確認する。

## 選定前に決めること

### データそのものが必要か

CSVやParquetなどを受け取り、自社で加工・分析する場合は、対象地域、更新頻度、履歴、位置精度、カテゴリー、IDの安定性を比較する。POI件数だけで品質は判断できない。

### システムへ組み込むか

地図、検索、ジオコーディング、経路、人流などをAPIで利用する場合は、料金単位、呼び出し制限、キャッシュや二次利用の可否、サービス停止時の設計を確認する。

### 分析環境を構築するか

自社の店舗、売上、顧客データと外部のPOI・人流を組み合わせるなら、既存のクラウド基盤に地理空間機能を近づける方法と、GISへデータを持ち込む方法がある。処理量、利用者の技能、権限管理、再現性で選ぶ。

### 完成した業務ツールを使うか

出店、商圏、販促など目的が明確であれば、データと分析が組み込まれた業務アプリケーションを選べる。導入は早い一方、独自データや分析ロジックをどこまで組み込めるかを確認する。

## 商圏分析におけるデータ解釈の支援

技研商事インターナショナルは2026年9月29日、GIS製品シリーズ全体の累計導入企業数が3,000社を超えたと発表した。単一製品の利用企業数や現在の契約数とは区別する。

MarketAnalyzer 5は統計・POI・自社データを重ねて分析し、商圏レポートAIで地域特性や出店ポテンシャルを言語化する。KDDI Location AnalyzerはKDDIとの共同開発による人流分析製品である。同社はデータ拡充、ノウハウの体系化、多用途展開、AIによる属人化解消を導入拡大の背景に挙げる。導入規模と分析精度・業務効果は別の指標であり、この発表は独立した効果検証ではない。

### 製品の導入実績を読む範囲

2026年10月20日の技研商事公式サイトは、MarketAnalyzerの導入実績を2,000社以上と表記し、ハフモデルによる集客力予測、グラビティモデル・重回帰式による売上予測、生成AIによる商圏構造の説明を案内する。既述のGISシリーズ全体の累計3,000社という発表とは、集計対象が異なる。数字だけを並べて利用が減ったと判断しない。

## 地図APIと高精度3次元データの提供形態

2026年10月1日のGFS解説は、ゼンリンの地図・GIS・APIと、ダイナミックマッププラットフォームの自動運転・ADAS向け高精度3次元地図を対比する。位置情報関連企業を一括りにせず、どのデータを、どの用途・製品形態で提供しているかを読む資料である。

投資教育メディアによる二次解説として参照し、収益見通しや投資判断をAtlasの評価として採用しない。

## 既存の業務台帳へ地図を加える

MAPPLE地図プラグイン for kintoneは、kintoneの住所データから地図へピンを配置する連携製品である。登録済みデータへの一括付与、条件別のマーカー変更、モバイルでの閲覧・編集を案内する。新たな分析基盤を作る前に、顧客・物件・点検先などの台帳を位置と結び付ける用途に当たる。

地図利用ライセンス込みの月額定額だが、GISデータの表示・図形描画は有料オプションと明記されている。kintoneの利用環境とプラグインの契約範囲を確認する。展示会での実演予定は、業務効果や精度の検証結果とは区別する。

## 施設選択から始める人流分析：Geo-Insight

ジオテクノロジーズは2026年10月5日、人流分析ツールGeo-Insightの提供を開始した。企業発表では、トリマ由来の1日10億件規模の位置情報と全国約230万施設を組み合わせ、施設の事前登録なしで来訪・属性・商圏を分析すると説明する。競合店舗の自動抽出、約10秒間隔の測位、期間をまたぐ来訪動向の比較を特徴としている。

発表時の価格は年間契約で月額20万円／ID（税別）。定額プランでは対象施設数・分析回数に制限を設けないとしている。GeoTechAgentとの連携は今後の予定であり、提供済みの機能とは分ける。

件数は位置情報レコードの規模であり、利用人数や分析精度ではない。来訪判定、標本の偏り、属性の取得・推定方法は導入前に確認する。発表は許諾を得たデータと匿名加工処理の利用を説明するが、Atlasでは実データや処理を監査していない。

## 購買データの対象市場と提供段階

True Dataは2026年10月7日、プロショップ向けPOS・販売管理システム「MUSASI」のコスモネットを完全子会社化するための全株式取得を決議したと発表した。食品・日用品中心の購買データに、建設・金物・住関連の市場を加える方針である。

同社は契約・データ保護を踏まえた標準化・統合を進め、長期的には地域・気象・住宅関連統計を組み合わせた需要予測を目指す。現時点で統合データを購入できる、または予測性能を実証済みという発表ではない。利用を検討する際は、対象業種・地域と、計画・提供中サービスを区別する。

プロ市場の購買が生活者需要の先行情報になるという点も、同社の活用構想として読む。データ量だけで予測の有効性を判断しない。

## 担保調査の情報を一画面へ集める

ZENRIN Maps Studioは、必要な地図コンテンツと機能を組み合わせるセミオーダー型の業務支援クラウドである。2026年10月8日の金融機関向け発表では、地番・路線価・用途地域などを一元確認し、調査資料用の地図を印刷する使い方を紹介する。

これは資料の収集・照合・作成を支援する例であり、担保価値をAIが自動決定する機能の発表とは区別する。データ・機能の契約範囲と情報の更新時点を確認する。展示会や講演日程は日次記録に残し、ここでは業務での役割を整理する。

## 防災・道路点検で異なるデータを組み合わせる

ゼンリンのCEATEC 2026出展発表は、次の3事例を紹介する。

| 事例 | 組み合わせる情報と用途 |
| --- | --- |
| KUMATREM | 道路ネットワーク、車両の走行実績、渋滞情報を重ね、被災地域周辺の交通状況を把握する |
| 動的リスクマップ | 建物の構造・築年数と時間帯別人流を組み合わせ、人的被害リスクの変化を可視化する取り組み。ジオテクノロジーズと連携 |
| RoadManager | 車載スマートフォンの画像からAIが道路損傷を検知し、位置・画像を地図で管理する。アーバンエックステクノロジーズと連携 |

地図を共通の位置合わせの基盤にし、観測データやAIの検知結果を業務へつなぐ例である。展示発表の確認であり、検知精度や人的被害予測の妥当性を本Atlasで検証したものではない。動的リスクマップは活用可能性を検証する取り組みとして読む。

## 車両の位置表示を運行管理につなぐ

昭文社HDとOrganonの「イマロケ」は、スマートフォン・タブレットで車両位置、現場連絡、走行履歴を扱うサービスである。QRコードや埋め込みタグから利用者向けの運行状況地図を公開できる。2026年10月19日の発表では、26台のスクールバスがある片柳学園への導入を紹介する。

発表時の料金は初期費用0円、車両1台当たり月額6,000円（税別）から。位置表示を増便・配車調整や利用分散へ結び付ける狙いであり、待ち時間の削減効果を測定済みとはしていない。完成した運行管理サービスの例で、汎用GISやAI分析モデルとは区別する。

## 広告配信地域と店舗データの購入単位

技研商事のエイエイピー事例は、KDDI Location Analyzerで観光地点の属性・流入元を確認し、広告の配信地域を絞った例である。ある地点の来訪者の約8割が東京・神奈川からだったとする。効率改善は導入先の報告であり、効果量や比較条件が示された因果検証ではない。

ReviewのYOROZU DATAは、2026年10月20日に東京23区・大阪市24区の飲食・理美容94パッケージを発表した。2026年8月までの店舗情報を区単位で購入できる。運営法人や開業推定日などを含むが、項目の充足は店舗によって異なる。オープンデータではなく購入型の提供であり、商圏が区境を越える場合は隣接地域と利用条件も検討する。
