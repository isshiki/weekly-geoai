# Maparium

Mapariumは、OpenStreetMapに登録された風車、城、飲食店、学校などの分布を、世界規模で眺める個人開発のWeb地図である。描画にMapLibre GL JSを使い、目的別のレイヤーを切り替えて地物の集まり方を探る。

## 使いどころ

「世界の風車はどこに多いか」「城や遺跡がどの地域に集まるか」といった問いの入口になる。単一テーマで地物を選び、広域で見比べるという地図表現の例である。OSMへの登録状況を示すもので、実在するすべての施設を網羅した統計ではない。
