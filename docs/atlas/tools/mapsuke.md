# Mapsuke

Mapsukeは、QGISのパネルからAIへ指示して地図作成や分析を進める、MIERUNEのオープンソースプラグイン（GPL v2）である。QGIS 3.44以降と、Claude CodeまたはCodex CLIの導入・認証が必要で、利用するAIサービスの契約またはAPIキーを別途用意する。

## 動かし方と再利用

QGIS側からCLIを呼び出し、AIが作ったPythonコードを実行して結果を返す。利用者によるMCPサーバーの設定は不要で、インストール済みのプロセシングツールも利用する。

開発元は、データ取得・集計・色分け・印刷レイアウト、図面の位置合わせ、衛星画像の指標集計などを紹介している。確認した処理はプロセシングスクリプトとして保存でき、入力を替えて再利用したり、Mapsukeを使わない人へ共有したりできる。座標系・保存先・命名規則はカスタムプロンプトで共通指定する。

## 実行確認と分析の検証

| モード | 記事が説明する動作 |
| --- | --- |
| Ask | 実行内容を毎回確認する |
| Auto | AIがリスクを判断し、必要と判断した操作で承認を求める |
| Full auto | 確認せず実行する |

生成コードはQGISと同じ権限で動く。ファイルの変更・削除や外部送信も可能であり、Autoは独立した安全性保証ではない。開発元は慣れるまでAskを推奨する。

掲載例は動作紹介で、分析結果の正確性は未検証と明記されている。処理の完了、見た目の整った地図、妥当な分析結果を分け、出典・集計条件を確認する。本Atlasでもプラグインを実行していない。

## 組織で導入するための研修と支援

MIERUNEは2026年10月29日、Mapsukeを使う公開講座・法人研修・導入運用支援を発表した。操作をAIへ任せても、データ構造、座標系、分析方法の基礎は必要とし、担当者による指示の設計と結果の検証を重視する。

新しいプラグイン機能の公開ではなく、環境準備から業務への組み込みを支援する動きである。研修の利用条件は案内元で確認する。
