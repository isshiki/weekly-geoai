# ゼンリン地図ナビ

ゼンリン地図ナビは、住宅地図とナビゲーションを組み合わせ、目的地周辺の詳細な道路・建物情報を案内に利用するサービスである。

## 確認したポイント

- 2026年8月の更新で、住宅地図上のカーナビゲーションに対応した。
- マンションやテナントビルを含む建物出入口の表示範囲を拡大した。
- テナント一覧から表札情報を確認でき、目的地直前の探索を支援する。

## 住宅地図を中心に使うプラン

2026年10月1日提供開始の「住宅地図プラン」は、住宅地図の閲覧回数・表示領域・地図移動の制限をなくす。表札・番地・建物名・テナント名などを確認し、配送・訪問・営業で目的地を探す用途を想定する。

10月2日の発表は、無料、スタンダード、住宅地図、スタンダード＋住宅地図の4プランを案内する。住宅地図プランと無料プランでは中型車以上のルートを利用できない。閲覧の制限解除と、利用できる車種・経路機能は分けて確認する。
