# ゼンリン地図ナビ

ゼンリン地図ナビは、住宅地図とナビゲーションを組み合わせ、目的地周辺の詳細な道路・建物情報を案内に利用するサービスである。

## 確認したポイント

- 2026年8月の更新で、住宅地図上のカーナビゲーションに対応した。
- マンションやテナントビルを含む建物出入口の表示範囲を拡大した。
- テナント一覧から表札情報を確認でき、目的地直前の探索を支援する。
