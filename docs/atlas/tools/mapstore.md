# MapStore

MapStoreは、複数の地理データをブラウザーで表示・利用するオープンソースのWebGISアプリケーションである。地図を描くライブラリ単体ではなく、レイヤーを選ぶ画面やウィジェットなどを備える。運用するアプリと接続先のデータサービスを用意する必要がある。

## データを集めて見る

2026.02.00の公式発表は、異なる形式・サービスを同じ地図で扱う機能を拡充している。

| 接続先・機能 | 使いどころと条件 |
| --- | --- |
| ArcGIS FeatureService | ベクトルデータを2D・3D表示。範囲ごとに段階的に読み込む |
| FlatGeobuf | リモートのファイルを読み取り専用レイヤーとして表示。表示件数の上限を設定できる |
| Panoramax | 道路沿いの画像を見る。利用するAPIや帰属表示を設定する |
| GeoNode API | カタログからデータを探す。カタログの画面構成も刷新された |

## 座標系と画面を管理する

Dynamic Projection Definitionsでは、権限を持つ利用者が座標系を検索・追加・削除できる。アプリを再配置したり設定ファイルを手で書き換えたりする手間を減らすが、座標系を提供するGeoServerのエンドポイントに依存する。画面だけで任意の環境へ自動対応するという意味ではない。

カスタムウィジェットは他プラグインの部品を表示できる。タイムラインも地図下部へ配置する構成に変わった。ここでは発表内容を確認しており、導入・性能試験はしていない。
