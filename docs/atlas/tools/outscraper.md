# Outscraper：事業者情報の補完

Outscraperは事業者情報の取得・補完を提供するクラウドサービスである。Google Maps Scraperで得る事業者情報に、取得可能な公開企業属性や連絡先を加え、市場調査や競合の整理に利用する。

## 補完で何が変わるか

2026年10月28日の発表は、複数の情報源を一つのデータセットへまとめ、出力を標準化する機能の拡充を説明する。既存のエクスポートとAPI連携を維持するとしている。自前の収集基盤を持たずに利用するクラウド型で、サービスの利用条件・費用を確認する必要がある。

## 読むときの注意

MarTech Cubeに掲載されたGlobeNewswireの発表転載を確認したもので、精度や網羅率の独立評価ではない。情報が公開されていても、全店舗の属性が揃うとは限らない。Google公式サービスでも、取得データをオープンデータとして配布する発表でもない。本Atlasでは取得・再配布の許諾範囲を検証していない。
