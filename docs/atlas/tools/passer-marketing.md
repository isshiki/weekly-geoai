# PASSER-MARKETING

PASSER-MARKETINGは、技研トラステムがunerryと連携して提供する商業施設向けマーケティング支援サービスである。2026年9月15日に提供開始を発表した。

## 組み合わせるデータ

PASSERの人数カウントによる来館数などの実測データと、GPS・ビーコン由来のスマートフォン位置情報による行動データを組み合わせる。居住地・勤務地は推定情報であり、実測の来館数と同じ性質の値ではない。

| メニュー | 主な分析対象 |
| --- | --- |
| 自店ターゲット分析 | 属性、商圏、来訪頻度 |
| 館内回遊・エリア分析 | エリア別来訪、ショップ間の併用 |
| マーケット分析 | 競合施設・周辺施設との関係 |

販促評価、テナント支援、リーシング、リニューアル検討などへの活用を想定する。発表はデータを組み合わせる構成を説明しているが、補正手順や精度検証の数値は示していない。

人数カウントシステムについては、画像を機器内で処理し、個人情報に関わる画像を保存しないと説明している。この説明を、位置情報を含む全データの保存方針へ拡張して解釈しない。
