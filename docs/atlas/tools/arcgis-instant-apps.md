# ArcGIS Instant Apps

ArcGIS Instant Appsは、作成したWeb地図を目的別のテンプレートに当てはめて、閲覧・比較・管理用のアプリにするサービスである。地図やレイヤーを用意し、作成に必要なArcGISのアカウントと権限を確認して使う。

## 使いどころと具体例

地域別の人口・所得などを見比べてもらう場合は、地図だけでなく指標を並べる画面が役立つ。組織内で空き物件などの台帳を扱う場合は、条件で絞って属性を更新する管理画面が必要になる。閲覧者向けと管理担当者向けでは、選ぶテンプレートも共有範囲も変わる。

| 目的 | 2026年11月更新の例 | 確認点 |
| --- | --- | --- |
| 複数の地域指標を見比べる | Indicatorsの指標表示・データ形式の判別 | 指標の単位・時点や地域の対応をそろえる |
| 台帳から対象を絞って編集する | Managerエージェントが条件抽出・属性編集を支援 | ベータ版。変更対象・変更値を確認する |
| 地図データを対話で探索する | Data Explorerの更新 | ベータ版。利用可能なデータや組織設定を確認する |

## AI機能と公開範囲

ManagerエージェントとData Explorerは、2026-11-20に確認した解説では、公開共有したアプリで利用できない。組織のAI利用設定と、データのフィールド名・説明などの準備も必要になる。誰でもアクセスできる地図に、そのまま対話AIを付けられる機能として紹介しない。ベータ機能は国内サポート対象外と案内されている。

EsriはGIS内のアシスタントや外部AIからの接続を広げる方向性も示している。ただし、製品全体の将来構想から、個別アプリですべての分析・編集が可能だとは判断しない。自分の契約・共有先・データで使える機能を確認する。本Atlasではアプリの作成や対話操作は未実施。
