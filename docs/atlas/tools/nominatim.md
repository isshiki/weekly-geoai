# Nominatim

NominatimはOpenStreetMap（OSM）のデータから住所・地名を検索するオープンソースのソフトウェアである。住所から位置を求めるジオコーディングと、座標から住所情報を組み立てる逆ジオコーディングに対応する。

## 利用形態と準備

自分のサーバーへOSMデータを取り込み、検索APIを運用できる。公式READMEはPython環境、データ取り込み、Webサーバー起動を案内する。ソフトウェアの自前運用と、公開サーバーの利用条件は別に確認する。OpenStreetMap公式サイトの検索結果を提供する仕組みの一つでもある。

## 検索と運用の確認点

- 結果はOSMの登録内容に依存する。逆ジオコーディングは現地住所を新たに測定するものではない。
- 2026年10月14日UTC公開の5.3.3は、重なるPOI付近の逆ジオコーディング、API入力検証、出力のエスケープなどを修正した。
- サーバー情報が漏れる可能性に対処し、デバッグ画面を既定で無効にする互換性変更がある。開発側は5.3.x利用者へ更新を推奨し、データベース移行は不要と説明する。

最新版を固定した導入手順ではなく、運用上の変更例である。本Atlasでは導入・移行試験を行っていない。

## 住所が見つかることと正しい場所に置けること

TerraLabの2026年10月19日の比較は、米国・フランス各100校について、住所から得た座標と公開された学校座標の距離を測る。米国ではNominatimが81件を検出し誤差中央値95m、同社AI Agentが93件を検出し184mだった。AI Agentの17件は1km超ずれた。検出数が多くても位置精度が高いとは限らない例である。

対象は学校名を除いた住所で、自社製品を含む提供元の実験である。フランスのBANと参照座標は共通する点が多く、独立した精度評価ではないと記事が注記する。日本の住所での優劣や全サービスの一般的な順位へ広げず、番地・道路・地域代表点のどの精度で返ったかも確認する。Atlasでは再実行していない。
