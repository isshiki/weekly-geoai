# 鉄道駅LOD MCPサーバー

鉄道駅LOD MCPサーバーは、日本の駅・路線・乗降客数を、ClaudeなどのMCP対応AIクライアントから取得するローカルサーバーである。サーバーの導入とクライアントへの登録が必要で、地図を表示する単独アプリではない。

## 駅や沿線を調べる入口

作者の2026年11月8日の紹介では、176事業者・約600路線・約1万駅を対象に11ツールを提供する。駅位置・路線形状をGeoJSONで取得し、2011〜2024年度の1日あたり乗降客数も参照できる。住所LOD MCPサーバーと組み合わせ、行政区の人口と駅の乗降客数を重ねた例がある。取得はMCPサーバー、依頼の解釈・結合・描画はAI側が担当するため、結合条件と人口・乗降客数の時点を確認する。

## 数値と経路の意味を確かめる

| 取得するもの | 確認すること |
| --- | --- |
| 乗降客数 | 事業者で算出基準が異なり、欠測駅もある。補正推定値は公表値と別に併記される |
| 駅・最寄り駅 | 同じ駅でも会社・路線ごとに別データとなる。距離は概数 |
| 路線長 | 線形から計算した長さと営業キロは定義が違う |
| 経路 | 隣接・乗り換えの接続に基づく参考情報。時刻表・所要時間・運賃・直通運転は扱わない |

経路の信頼性ラベルも正しさの保証ではなく、乗り換え案内の代替にはしない。データはCC BY-SA 4.0で、作者は生成地図などを公開する際の出典表記と同じライセンスでの公開を案内している。ファイル出力自体には出典が入らないため、別途表記する。共有サービスには利用制限が生じ得る。Atlasでは導入・経路探索・描画を実行していない。
