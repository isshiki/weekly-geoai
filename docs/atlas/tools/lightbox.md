# LightBox

LightBoxは、住所、土地区画、建物外形、所有者、物件属性などを結び付け、不動産調査や立地選定を支援する位置情報データと分析製品を提供する。

## 確認したポイント

- Connected Dataには住所点、区画境界、建物外形、所有者・郵送先、物件属性、近隣地域境界などが含まれる。
- 米国のParcel Boundariesは、領土を含む3,100超の郡を対象とし、300超の不動産・税務属性を持つと説明されている。
- LightBox Visionは地図を使った物件調査・分析・管理、CanMapはカナダの区画データを扱う。
- 製品ページは1億5,000万超の区画、1億5,400万超の建物外形、2億5,000万超の住所を掲げる。2026年9月15日に確認した掲載値であり、ページの公開日や各件数の基準日は明記されていない。
