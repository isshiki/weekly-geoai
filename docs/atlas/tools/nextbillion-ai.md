# NextBillion.ai

NextBillion.aiは、配送などの経路計算・最適化をアプリへ組み込むAPIやSDKを提供する商用サービスである。利用にはアカウント、契約条件の確認、アプリへの組み込みが必要になる。

## 経路計画と現場での利用

2026年第3四半期の公式更新は、次の用途を紹介する。

| 機能 | できること | 確認すること |
| --- | --- | --- |
| HOS API | 累積運転時間や残り勤務時間を踏まえ、休憩・休息を含む行程の実行可能性を評価する | 対応する地域の規則と入力条件 |
| オフラインのナビゲーションSDK | 地図を事前取得し、通信がない場所で案内・再経路探索を行う | 地図の取得範囲、端末、同期条件 |
| Location Reasoning AI | MCPを通して場所検索、道路に沿った距離・時間、到達圏、複数地点の経路などを扱う | 接続権限、利用できるAPI、結果の検証 |

MCPは、AIから外部ツールを呼び出すための接続方法である。自然言語から経路を作れても、車両や勤務時間などの制約を正しく入力する必要は残る。

## 確認範囲

公式発表を整理したもので、APIやSDKは試していない。HOS対応の記述を日本の勤務時間規制への適合保証とは扱わず、対象地域・規則・契約の確認が必要である。
