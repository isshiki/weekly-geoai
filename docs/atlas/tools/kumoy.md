# Kumoy

Kumoyは、QGISで作成した地図をクラウドへ保存し、Webで共有するサービスである。MIERUNEの解説は、操作可能な地図を外部ページへ埋め込む方法を示す。

## Webページへの埋め込み

生成したiframeコードを貼り付けると、移動・拡大縮小・レイヤー切り替えができる。地図名、説明、レイヤー一覧、操作ボタンの表示と、初期中心位置・ズームを調整できる。

対象は「公開」または「保護されたアクセス」のマップである。「非公開」は対象外であり、共有設定の変更は閲覧可能な人の変更を伴う。Notionでは公開マップのURLから埋め込める。CMSによってはiframeが削除されるため、掲載先でプレビューを確認する。
