# Galuchat

Galuchatは、公開されているポリゴン地図をラスタデータへ変換し、座標から行政区域などを検索する逆ジオコーダーである。地理データと検索エンジンをブラウザ側に保持する構成を取り、外部APIへ座標を送らずに処理できる。

## 確認したポイント

- WebMCP対応により、AIから1地点または複数地点の逆ジオコーディングを呼び出せる。
- `resolve-position`と`resolve-positions`を使い、座標やGPSログをブラウザ内で行政区域へ変換する。
- 日本の行政区域、日本の丁目・番地レベル、世界地図の3種類のデータセットが用意されている。
- APIキーや外部APIの呼び出し回数を必要とせず、大量座標の一括分類や移動経路が通過した地域の集計を想定している。
- 高精細な住所検索の代替ではなく、行政区域を大量かつ高速に検索する用途に位置付けられている。
