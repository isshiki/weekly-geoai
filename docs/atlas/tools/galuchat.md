# Galuchat

Galuchatは、緯度経度から行政区域や統計区の地名を取得する逆ジオコーダーである。区域のポリゴンを領域ID付きのラスタへ変換・圧縮し、外部APIに座標を送らず検索する。

## 使いどころと準備

ブラウザー上のデモのほか、Galuchat GIS SDKで自分のアプリへ組み込める。JavaScript・Java・Python・C++に対応し、区域データ、対応する地名辞書、読み出しコードを配置する。オフラインの座標分類や、移動経路が通過した地域の集計が用途になる。

2026年10月12日の作者記事では38か国・地域、45データセットを公開している。日本の行政区域の例は0.0001度間隔（記事では約11m）で4.47MiBであり、地名辞書は別である。度単位の格子なので、実距離を全方向・全緯度で固定11mと解釈しない。

## 検索の流れと境界の扱い

| 段階 | 処理 |
| --- | --- |
| 座標を受け取る | 経緯度から格子内の位置を求める |
| 領域を探す | 圧縮データの必要部分から領域IDを読み出す |
| 名前へ変換する | 対応する辞書から地名を取得する |

領域IDはデータセット内部の番号で、自治体コードと同じとは限らない。ラスタ化で境界が丸められるため、境界付近や小さな区域は元ポリゴンの判定と異なる場合がある。細かな格子を選んでも、市区町村のデータが番地単位になるわけではない。

## AIとの接続

9月に確認したWebMCPの記事では、ブラウザー内の逆ジオコーディングをAIから呼び出し、1地点・複数地点を処理する例を紹介している。SDKの4言語対応とWebMCPによるブラウザー接続は別の利用方法である。
