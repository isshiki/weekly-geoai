# ShadeMapと建物データの更新

ShadeMapは、建物の外形や高さなどのデータを利用する日影地図サービスである。2026年9月24日の公式投稿では、Overture Mapsの建物データを9月23日版へ更新したと説明している。

## 編集からサービス反映まで

投稿は、OpenStreetMapに建物の高さや外形を投稿すると、1カ月以内にShadeMapへ反映される見込みを示す。編集した直後にすべてのサービスが同時更新されるという説明ではない。元データの編集、配布版の更新、利用サービスへの取り込みを分けて確認する。

この期間は投稿者の見込みであり、個別の編集について反映を保証したものではない。今回、建物の追加や更新遅延の実測は行っていない。
