# TorchGeo

TorchGeoは、地理空間データを用いた機械学習向けにデータセット、モデル、学習処理などを提供するライブラリである。

## 保守更新で確認する点

2026年9月29日公開の0.10.1は、新機能・API変更のない不具合修正・保守リリースである。細かな差分を新機能として紹介せず、使用中の処理に影響する修正を確認する。

| 対象 | 主な修正 |
| --- | --- |
| データ分割 | random_grid_cell_assignmentでCRSを保持 |
| ダウンロード | 公開S3の匿名アクセス、不完全な取得の検知 |
| モデル | OlmoEarthの学習済み重み読み込み、Copernicus-FMの型処理など |
| 学習 | MoCo・SimCLRで標準化済み入力に対するデータ拡張を修正 |

結果の再現性を確認する際は、モデルだけでなく入力処理やデータ分割の版も記録する。今回の確認はリリースノートのみで、学習の再実行は行っていない。
