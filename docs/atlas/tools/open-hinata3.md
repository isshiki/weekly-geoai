# OH3（Open Hinata 3）

OH3は、登記所地図、地番図、地形、古地図などを重ねて扱う日本向けWebGISである。公式概要は700種以上のレイヤー、地番検索、2画面・4画面比較、データ入出力を案内している。軽量版の[今昔マップビューア](oh3-konjaku.md)とは別に、アプリ本体を扱うページである。

## 地番図と任意座標の図面

| 対象 | 確認した内容 |
| --- | --- |
| 全国地番図公開マップ | 有志の情報公開請求と自治体オープンデータを整備したもの。2026年9月19日時点で1,048市区町村を掲載 |
| 登記所地図の任意座標系 | 開発者の9月25日投稿は、地番検索後に図郭ごとの図面を表示できると説明 |

任意座標系の筆が検索できることと、地球上の正確な位置へ配置できることは区別する。対象の1億2,800万筆は開発者の公表値であり、今回検索件数を実測していない。公式概要も、地番図等の表示が境界確定や登記の判断を代替しないと説明している。

## 地図を合成して読む

開発者は、戦前の旧版地形図に現代の「人工地形」を合成し、埋め立てや造成を読む例を紹介している。異なる時代の地図を組み合わせる利用例であり、ここで造成量や発生時期の定量的な検証が示されているわけではない。

閲覧・地番検索は無料で、処理や出力などにはポイントを使うと案内されている。個別機能の必要ポイントは利用時に確認する。本ページではログインや操作検証は行っていない。
