# LAPと人流アナリティクス

Location AIのLAPは人流分析・広告配信・データ連携を扱うサービスである。2026年9月25日の刷新では、無料の「人流アナリティクス」に、地点を登録すると来訪傾向や変化点を文章で示すAIサマリーを搭載した。プロンプト入力を前提にせず、算出済みの数値を参照して説明すると同社は述べている。

## 発表時の提供条件

| メニュー | 条件 |
| --- | --- |
| 人流アナリティクス | 無料、2地点・1 IDまで |
| LAP STARTER | 月額1万円（税別）、10地点・1 ID、初期費用不要 |
| LAP BUSINESS | 月額30万円（税別）、広告配信と広告接触層の来訪計測に対応。広告費は別途従量制 |

PLUS以上には初期費用15万円（税別）がある。上記は2026年9月25日の発表に基づく条件であり、契約時には最新の料金を確認する。

## 分析結果の読み方

AIによる説明の生成と、元の人流データの品質・推計精度は別々に確認する必要がある。広告接触層の来訪を測る機能があることだけで、広告がなければ起きなかった来訪の増加まで証明できるとは判断しない。サービスの精度や広告効果は本ページでは実測していない。

## 同じ会場の公演を比較する人流分析

2026年9月29日のLocation AI記事は、同年2月に東京ドームで開催されたFRUITS ZIPPER・RIIZE・Vaundyの公演を、日経エンタテインメント！が同社データで比較した事例を紹介している。匿名化・統計化したデータから、来訪元、開演前の到着時間、年代・性別の構成を可視化する。

同じ会場でも、早くから集まる公演と開演直前に集中する公演があるという。チケット購入情報とは異なる行動の側面を扱うが、位置情報から来訪を判定する条件や対象者の偏りを確認して解釈する必要がある。今回確認したのは提供元の紹介記事であり、会員限定記事の詳細な数値や推計精度までは検証していない。
