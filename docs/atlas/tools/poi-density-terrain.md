# にぎわいの地形図と駅Tier表

「にぎわいの地形図」と「駅のにぎわいTier表」は、POI（店舗・施設）の登録密度を眺め、街の集積を比較するブラウザー向けの個人作品である。一色政彦が公開しており、地形図の高さやTierは人出・売上・実際の標高を表さない。

## 地形と順位で眺める

Foursquare OS Placesの2026年9月15日版から、閉店が判明した登録を除く約1億件を集計する。近い登録ほど強く影響するよう200mの広さでならし、密度を色・等高線・3Dへ変換する。街の形や路線沿いの集積を眺め、詳しく調べたい地域を探す入口になる。

| 表示 | 何を表すか |
| --- | --- |
| 地形図の山 | ならしたPOI登録密度。実在の山ではない |
| 参照点の数値 | 駅や街の参照位置から直線800m以内の最大密度 |
| 駅Tier | 全国9,032駅の最大密度に基づくSS〜Dの区分。SSは上位約1％、Sは次の約4％ |

地域・路線で絞り込んでもTierは全国基準のままである。国土数値情報N02/N03を駅・地域に用い、駅カードから判定理由や周辺地図へ移動できる。地形図の現行記事は13,235参照点のCSVも案内する（2026年10月16日確認）。

## 読み取れる範囲

半径800mは徒歩圏や独立した商圏ではなく、近くの駅が同じ最大密度地点を共有することもある。山の数や高さを、そのまま店舗数や需要へ置き換えない。地域ごとの登録の充実度、閉店情報の不足や重複も結果へ影響する。

地形図は800件/km²を表示下限とするため、色のない場所にも施設はあり得る。出店判断には人口・競合・交通・現地情報などを合わせて確認する。Atlasでは集計やアプリ操作を再実行していない。
