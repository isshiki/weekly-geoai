# GIS Career Hub

GIS Career Hubは、GIS、リモートセンシング、WebGISなど地理空間分野の求人と学習資料を集めるサイトである。

## 探せる情報

- 専門分野別・国別の求人と、地図からの求人探索。
- MapLibre GL、PyQGIS、PostGISなどの技術学習への入口。
- フリーランス向けの見積もりや業務範囲を考える資料。

2026年9月23日のトップページには日本の求人も表示されていた。掲載件数は変動するため固定的な市場規模として扱わず、応募時は雇用主の原掲載で募集継続、勤務地、勤務形態、要件を確認する。掲載の正確性に関するサイト側の説明は、こちらで全求人を検証したことを意味しない。
