# ArcGIS for Teamsの対話検索

ArcGIS for Teamsは、Microsoft TeamsからArcGISの地図や資料を探し、共有するための連携アプリである。対話AIは既存の検索画面を自然言語で使う機能で、必要なデータの名前を知らない人にも検索の入口を提供する。

## 何を探せるか

「組織内の人口に関するフィーチャレイヤー」のように、テーマ・コンテンツの種類・検索先を組み合わせる。地図、レイヤー、ファイル、シーン、アプリなどを対象とし、自分・グループ・組織・Living Atlas・公開コンテンツから検索先を選べる。理解できない質問には関連候補や具体化の案内を返し、従来検索へ戻る経路もある。

この発表で確認できる中心機能はコンテンツの検索である。質問だけで空間集計や予測まで自動実行する機能としては扱わない。[Planet AI app](planet-ai-app.md)の画像を基にした場所探しとも区別すると、必要な道具を選びやすい。

## 利用条件

2026年11月5日の公式記事ではAIアシスタントはベータ版。Viewer以上のアカウントに加え、アプリ内の有効化と、組織側のAI利用許可・ベータ機能のブロック解除が必要である。設定が見えない場合は組織管理者への確認が案内されている。Atlasではアカウントを使った動作や検索精度は未検証。
