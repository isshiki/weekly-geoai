# THE MAPとDiground

THE MAPは、利用者が作った地図の公開スポットを、趣味や地域から探せるWebサイトである。地図を作成・共有するアプリはDigroundという名称で、iOS・Androidに対応する。

## 自分の関心から近くの場所を探す

ディグランドの2026年11月3日発表では、御朱印・ロケ地・カフェなどのジャンルや市区町村ごとに、複数の地図のスポットをまとめて表示する。現在地から近いスポットを探す機能もある。店舗を網羅する用途より、投稿者独自の切り口で行き先を発見する入口として読める。

## 掲載数と利用条件を確認する

発表時の公開対象は22,000件超で、アプリ全体の累計登録142万件超とは範囲が異なる。公開設定と一定条件を満たす情報が掲載される。個人は原則無料と説明されているが、公開スポットを自由に一括取得・再配布できるオープンデータという意味ではない。

本Atlasでは企業発表を確認した。アプリの操作、個々の投稿の鮮度・正確性、データ再利用条件は未検証。地図の作成・検索にAIが必須という説明ではない。
