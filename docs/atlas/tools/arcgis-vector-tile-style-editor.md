# ArcGIS Vector Tile Style Editor

ArcGISのベクタータイル背景地図の見た目を編集するブラウザー用ツールである。背景の色やラベルを用途・読者に合わせて調整する。紹介された保存手順にはArcGISアカウントとコンテンツ作成権限が必要になる。

## データと見た目を分ける

| 編集する対象 | 変更例 |
| --- | --- |
| 背景の地物グループ | Quick editで水域・陸地・道路などをまとめて配色する |
| ラベル | 色、書体、サイズを調整する |
| 保存したスタイル | 地図に追加し、分析結果に合う背景として利用する |

地物の元データを変更する操作とは異なる。背景とラベルが別レイヤーの場合はそれぞれ編集・保存する。2026年10月29日更新の記事では、子どもに水域が伝わりやすいよう灰色から青へ変える例を紹介している。配色は好みだけでなく、読者が何を見分けたいかに合わせて選ぶ。

## 確認した範囲

原記事は2019年9月6日公開で、今回は手順の更新である。製品の新機能公開とは扱わない。Atlasでは編集・保存操作を実行していない。
