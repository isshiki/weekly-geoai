# MachGL

MachGLはGeoloniaが開発するWeb地図描画ライブラリで、Webサイトへ地図や自分のデータを重ねるために使う。2026年10月21日の発表では、11月9日にCDNで提供を始める予定である。正式公開済みとは扱わない。

## どのような地図を想定するか

店舗案内などのモバイル向け地図と、建物や地形を見せる3D表示を想定する。発表ではgzip約98KB・依存ライブラリ1つと説明し、WebGL2で描画、Web WorkerでタイルやGeoJSONの解析・図形生成を行う。

| データ・表現 | 発表で案内する機能 |
| --- | --- |
| 店舗や施設の点 | GeoJSON、クラスタリング、ヒートマップ、HTMLマーカー |
| 画像・動画 | 地図への重ね合わせ |
| 地形・建物 | 陰影と立体表示、PLATEAUのLOD1～3 |

## 利用前に確かめること

公開されたデモと、実際に導入するライブラリの仕様は分けて確認する。バンドルの小ささだけで、同じデータを表示したときの速度やメモリー使用量の優劣は決まらない。対応ブラウザー、スタイルや既存コードとの互換性、利用許諾、配信料金を確認する。

Geoloniaの地図デザインを名前で指定して使う方法にはAPIキーを案内している。発表だけからOSSや無償利用を断定しない。Atlasでは性能比較やデモの操作検証を行っていない。
