# MovingPandas

MovingPandasについて、開発者のAnita Graserが公表した開発拠点の移行方針を整理する。

## 開発拠点

2026年9月14日の告知では、残るMovingPandasリポジトリを今後数週間でCodebergへ移す予定としている。

- 今後の開発はCodebergへ移す方針である。
- GitHubのリポジトリは当面読み取り専用ミラーとして残す予定である。
- GitHubのIssueとPull Requestは停止する予定である。
- Codeberg側のLLM利用ポリシーが適用されると案内している。

この記録は告知時点の予定であり、個々のリポジトリの移行完了を確認したものではない。貢献先を選ぶ際は対象リポジトリの案内を確認する。
