# STLOCAL

STLOCALは、ゼンリンの観光情報、電子チケット販売、デジタルスタンプラリーを扱う観光アプリである。利用を通じて得る周遊・施設利用データの可視化と分析を、自治体や観光事業者の施策検討にも利用する。

## 確認した提供内容

2026年9月17日の出展発表では、同月時点で九州7県18エリア、累計約16万ダウンロード、電子チケット約9万枚の販売と説明している。これらは企業公表値で、アクティブ利用者数や地域全体の観光客数とは異なる。

ツーリズムEXPOジャパン2026への出展予定は9月24〜27日である。同時に紹介されるLOCAYELLは仮称・参考出展の別サービスであり、STLOCALの提供済み機能には含めない。
