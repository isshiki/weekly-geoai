# 高徳地図（AMAP）

高徳地図（AMAP）は、アリババグループ傘下の中国向け地図・ナビゲーションサービスである。地図と経路案内に加え、店舗検索や配車など、移動中の目的地選択に関わる機能を提供する。

## 日本の事業者にとっての接点

Hakuhodo DY ONEは2026年9月、AMAPの公式パートナーとして日本企業・自治体向けの支援サービスを開始した。訪日中国人を対象に、次の施策を扱う。

- 店舗や施設のPOIを登録・最適化し、中国語などで正確な情報を掲載する。
- 周辺検索やルート検索のタイミングに合わせて情報を届ける。
- 商業施設などでデジタルクーポンを配布する。
- 地図上の表示、詳細ページの閲覧、店舗までのルート検索をPOI単位で計測する。

一般的な広告の表示回数だけでなく、「地図で見つける、詳細を見る、経路を調べる、現地へ向かう」という行動をPOIと結び付けて扱う点が特徴である。店舗名、住所、営業時間などの情報を最新に保つ運用が前提になる。

## 確認時の規模

Hakuhodo DY ONEの発表は、QuestMobileの2026年6月データを基に、AMAPの中国国内の月間アクティブユーザーを9.1億人超としている。この数値は調査時点と定義を伴うため、固定的なサービス規模としてではなく発表時点の参考値として扱う。
