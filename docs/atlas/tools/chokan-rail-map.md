# 鳥瞰路線図

鳥瞰路線図は、全国の鉄道沿線を斜め上から眺めるブラウザー向け地図である。chizutodesignが吉田初三郎の表現を参考に制作した個人作品で、沿線の山や名所の位置関係を探索できる。

## データと見せ方

国土地理院の標高とOpenStreetMapなどを使い、高さを強調して遠景を圧縮し、路線が画面を横切る構図を自動で作る。ズーム・スクロール、視点反転、乗り換え先の路線への移動、現在地付近・ランダムな路線の表示を案内している。

名所候補はOSMとWikidataから抽出し、Wikipediaの記事言語数・日本語版の閲覧数、路線からの距離、ラベル間隔で選ぶ。地図に掲載されたかどうかは場所の価値を示さず、閉館・廃止した施設が含まれる場合もある。

## 確認すること

- 地形を誇張した鑑賞・探索用の表現であり、画面上の距離や高さを実測値として読まない。
- 路線・駅・乗り換えも機械的に決めるため、実際と異なる場合がある。
- 公式説明を確認した。地図操作や表示の再現性は未検証。公開日は確認できなかった。
