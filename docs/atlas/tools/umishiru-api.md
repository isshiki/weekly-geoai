# 海しるAPI

海しるAPIは、海上保安庁の海洋状況表示システムに掲載する海洋情報を、外部の地図やGISへ取り込むためのAPIである。利用にはサブスクリプションキーが必要で、継続利用時は利用登録を申請する。

## GISへの接続と使いどころ

v3はArcGISの標準的なサービスを基盤とする提供方式である。ESRIジャパンの例では、ArcGIS OnlineのMap Viewerへサービス定義URLを指定し、カスタムパラメーターにキーを設定してデータを追加する。

航行警報・海上構造物などを気象情報と重ね、沿岸の状況をまとめて確認する用途を示している。API利用条件に加え、接続先のGISと重ねる気象サービスの利用条件も別途確認する。キーの実値を公開資料へ記載しない。

## 提供段階と運用条件

2026年10月9日の公式ポータル確認では、v3ベータ版は8月27日に開始済み、正規版は10月から段階的に提供予定と案内されている。利用する情報項目ごとに提供状況を調べ、全項目が正式提供済みと解釈しない。ここでは実際のAPI接続は検証していない。

更新時点、提供停止の案内、データの用途・制限を確認する。地図で情報を重ねられることだけで、その時点の航行やレジャーの安全が保証されるわけではない。
