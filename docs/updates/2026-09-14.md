## 国土数値情報

国土交通省が提供する約190種類のGISデータを、収録分野、形式、時点・定義・CRSなどの確認点、GeoAIで基礎データとして使う際の注意に分けて整理した。AIによる土地利用データ整備と、ダウンロード基盤刷新の動きも追記した。

[Atlas](../atlas/data/national-land-numerical-information.md) / [国土交通省](https://nlftp.mlit.go.jp/ksj/) / [取材記事](https://internet.watch.impress.co.jp/docs/column/chizu3/2123012.html)

## Felt

Feltを、既存のQGIS、PostGIS、データウェアハウス、クラウドストレージの先で、地図表示・共有・ダッシュボードを担うWeb GISとして整理した。COG、STAC、GeoParquetへの対応と、Enterprise向けMCP Serverの役割・権限・導入時の確認点も記載した。

[Atlas](../atlas/tools/felt.md) / [Felt MCP Server](https://felt.com/blog/introducing-felt-mcp-server) / [解説記事](https://qiita.com/rino_yume/items/b76443c5010bf0de2ceb)

## 地域別最多カテゴリ地図

寿司チェーンとGMSの2つの地図をもとに、地域ごとに最多カテゴリーだけを塗る表現を整理した。対象集合、集計単位、基準日、1位と2位の差、ブランドと資本系列を明示し、件数や構成比へ到達できるようにする方法をまとめた。
