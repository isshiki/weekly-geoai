# 2026年9月9日の更新

## MapLibre GL JS

WebGLでベクタータイルを描画するライブラリの役割と、v6.8.0のAPI追加、terrain・シェーダー・Marker生成の最適化、globeやタイルに関する修正を整理した。

[Atlas](../atlas/tools/maplibre-gl-js.md) / [v6.8.0](https://github.com/maplibre/maplibre-gl-js/releases/tag/v6.8.0)

## 全国メッシュデータのWeb配信

全国250mメッシュ約802万件の実測をもとに、GeoParquetを原本、DuckDB Spatialを検索、PMTilesを描画へ使い分ける構成と、ズーム別LOD、詳細APIの役割を整理した。データフローは独自SVGで追加した。

[Atlas](../atlas/methods/national-grid-web-delivery.md) / [検証記事](https://qiita.com/rino_yume/items/dd7c105cf37198bedc13)

## Portolan

GeoParquetの空間順序・row group統計、PMTilesのスタイル、COGのoverview・統計、HTTP Range RequestとCORSなど、ファイル変換だけではない公開品質の要件を追記した。

[Atlas](../atlas/data/portolan.md) / [仕様](https://github.com/portolan-sdi/portolan-spec) / [解説](https://qiita.com/rino_yume/items/9b0ff6dfa6d7ad5f3f83)

## CARTO MCP Server

AIエージェントから地図、Workflows、空間分析などを操作する接続層として、Claudeでの接続、権限継承、監査、再実行可能なWorkflowの考え方を整理した。

[Atlas](../atlas/tools/carto-mcp-server.md) / [公式記事](https://carto.com/blog/geospatial-analysis-claude-mcp-server/)
