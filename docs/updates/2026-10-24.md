## 今日の取り込み

提供6件と追加検索1件を日次記録へ保存した。PDIは10月6日に扱ったテーマの補足として統合。等時線APIも新規発表とは扱わず、既存の公式資料として整理した。

- [MapStore 2026.02.00 Release](https://www.geosolutionsgroup.com/blog/mapstore-2026-02-00-release/) → [Atlas](../atlas/tools/mapstore.md)：ArcGIS FeatureService・FlatGeobufを2D／3Dで表示し、PanoramaxやGeoNode APIに対応。座標系を画面から管理できる。FlatGeobufは読み取り専用で、座標系管理にはGeoServer側の対応も必要。
- [等時線 API](https://developers.google.com/maps/documentation/isochrones?hl=ja) → [Atlas](../atlas/methods/location-paas-selection.md)：Google Maps PlatformのIsochrones APIは指定時間内の到達範囲を計算する。道路への接続位置や移動条件が結果に関わる。既存機能の資料確認であり、今回の新規公開とは扱わない。
- [Routes API release notes（2026年10月23日）](https://developers.google.com/maps/documentation/routes/release-notes#October_23_2026) → [Atlas](../atlas/methods/location-paas-selection.md)：Navigation SDKへ渡すルートトークン内の経路設定をアプリ側より優先する変更。計画経路への追従を改善するが、交通状況などによる再計算までなくなるわけではない。
- [人口動態の分析情報の概要](https://developers.google.com/maps/documentation/population-dynamics-insights/overview?hl=ja) → [Atlas](../atlas/methods/spatial-embeddings.md)：検索・施設・混雑・天気などの集計情報をS2レベル12の330次元の地域表現にまとめ、BigQueryで提供。正確な施設件数などはPlaces Insightsと組み合わせる。10月6日の既報テーマを補足。
- [【DuckDB】 先日リリースされた 2.0 が地理空間データにもたらすもの](https://note.com/pacificspatial/n/n1947bdb5e851) → [Atlas](../atlas/tools/spatial-sql-engines.md)：DuckDB 2.0と地理データ分析を解説。全国約2,900万農地区画・約4.5GBのファイルから必要列を読み約40秒で属性集計した例を紹介。測定は著者の環境による。サーバー機能は公式発表に照らし既存機能の改善として整理。
- [Visualize points and routes with GeoJSON in Amazon Quick Sight layer maps](https://aws.amazon.com/blogs/machine-learning/visualize-points-and-routes-with-geojson-in-amazon-quick-sight-layer-maps/) → [Atlas](../atlas/tools/amazon-quick-sight.md)：レイヤーマップがGeoJSONのPoint・LineStringに対応。共通キーで指標を結合する。最大100MBで、指標の更新と形状の更新は別。地点・経路を変えるにはGeoJSON更新とダッシュボード再公開が必要。
- [What's new in DuckDB 2.0, tested on a billion rows](https://plotly.com/blog/duckdb-2-0/) → [Atlas](../atlas/tools/spatial-sql-engines.md)：PlotlyがOvertureのPOIをH3へ集計する地図デモを公開。速度比較に加え、同じ登記住所への事業者集中で密度が歪む例を扱う。座標への集中を除外する閾値はこのデモの処理で、一般的な重複判定基準ではない。

## 検証と補足

全7件の本文を確認。DuckDBのサーバー機能は公式発表で初出時期を照合し、2.0での改善に修正した。公式発表は補強資料としてAtlasの出典へ追加し、別のニュースとして重複計上していない。速度の数値は記事内の測定であり、再実行していない。

Quick Sightは指標と形状の更新を区別し、複数の地図ビジュアルを重ねる条件も記載。PDIの330次元を施設件数そのものとは扱わず、集計値との併用を説明した。

## 図版の判断

- MapStore：接続先・条件の表で比較できるため図版追加なし。
- Amazon Quick Sight：指標と形状の更新を表で区別。実画面を未操作のため図版追加なし。
- 位置情報PaaS：既存の比較表を維持し、到達圏の条件と経路トークンを文章で補足。図版追加なし。
- 地域埋め込み：既存図を維持し、圧縮特徴と件数の違いを文章で補足。
- 空間SQLエンジン：既存役割表を維持。異なる条件の性能値を一つのグラフにせず文章で整理。
- 知識マップ索引：MapStoreとQuick Sightをナビゲーションと同じ順序で追加。図版不要。
