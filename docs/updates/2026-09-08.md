# 2026年9月8日の更新

## geoparquet-io

v1.4.0で追加された、A5・H3・行政区画への集約、overview生成、PMTilesピラミッド化による低ズーム表示の処理を整理した。STR空間ソート、GeoArrow出力、WFS自動分割、互換性上の注意も追加した。

[Atlas](../atlas/tools/geoparquet-io.md) / [Changelog](https://geoparquet.io/CHANGELOG/)

## pricemap

マクドナルド単独のページをサービス全体へ統合し、6チェーンの代表商品価格を店舗単位で比較するPOI活用事例として再構成した。

[Atlas](../atlas/cases/pricemap.md) / [サービス](https://pricemap.s-otk.com/)

## 人流データの計測誤差と推計誤差

センサーによる取りこぼし・過剰検知と、捕捉率による拡大推計を分けて整理した。捕捉率の違いが推計人数へ伝わる例を独自SVGで追加した。

[Atlas](../atlas/data/human-flow-data-quality.md) / [解説](https://note.com/pacificspatial/n/n640ded7f31f3) / [国土交通省の手引き](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/chirikukannjoho/content/001733098.pdf)

## 小売出店候補地のロケーションインテリジェンス

SENSY GeoScopeのベルクへの導入を国内事例として追加した。POS・商圏・競合・人口データを使う売上予測、条件変更と競合出退店のシナリオ比較、検証値を読む際の注意を整理した。

[Atlas](../atlas/cases/retail-site-selection.md) / [発表](https://prtimes.jp/main/html/rd/p/000000059.000013501.html)
