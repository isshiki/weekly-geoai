# 2026-11-06 更新履歴

[INTERNET Watchの11月4日付レポート](https://internet.watch.impress.co.jp/docs/column/chizu3/2152304.html)を収録。STACで観測データを探し、COGから必要な部分を読む例として、富士山周辺の地形と地表面温度をQGISで重ねる実演を追加した。既存の役割分担図を生かし、操作画面はJAXAの手順へ案内した。

## 追加収録

11月7日に、11月6日分としてNavigation SDK、Placer.ai、Review、GeoMakie、CARTOの5件を追加。GEXTの転載は11月3日の公式発表と重複する関連資料として記録し、個人投稿はURL・機能名が未確認のため保留した。補完検索は新たに採用する題材がなく追加0件。

Atlasではナビ中の先読み、地図アプリの社内共有、イベント前後の行動、開業件数の読み方を既存4ページへ統合した。各ページの追記は短い説明で伝わるため、新規図版は追加しなかった。製品の実動作や記事のコードは未検証。先に収録したJAXAの記事を含め、11月6日最初の変更前から更新箇所を生成する。
