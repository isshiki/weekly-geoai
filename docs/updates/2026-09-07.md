# 2026年9月7日の更新

## 人流データの時間処理と集計定義

不規則な位置観測から、セッション化、滞在・来訪判定、固定窓・移動窓による集計へ進む考え方を整理した。ユニーク人数と延べ回数、時間・空間粒度によって結果が変わる点もまとめた。

[Atlas](../atlas/methods/human-flow-time-processing.md) / [解説](https://note.com/pacificspatial/n/n03ef6902a12c) / [本人執筆記事](https://blog.masahiko.info/entry/2026/09/07/200718)

## Google Places Insights

2024年1月まで遡る月次スナップショット、評価・評価件数、2時点の施設数を比較する `PLACES_COUNT_CHANGE` と、H3を含む集計関数の追加フィルターを整理した。

[Atlas](../atlas/tools/google-places-insights.md) / [リリースノート](https://developers.google.com/maps/documentation/placesinsights/release-notes)
