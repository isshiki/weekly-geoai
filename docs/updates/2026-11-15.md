## 収録した情報

- [ブランドがフィットする「場所」](https://cloud.google.com/blog/ja/products/maps-platform/the-geography-of-brand-fit/)：AKQAが米国11ブランド約8.5万店舗を、地域の同業態平均に対する評価で比較。Places InsightsとPDIを使い、学習から外した州と新店1,445店で評価傾向を検証したと報告する。予測対象は相対的な店舗評価であり、売上・因果・個人の好みではない。
- [インテージとSENSY、「SCI-CODE」とAIを活用した店舗開発支援の高度化に向け連携を開始](https://www.intage.co.jp/news/9027/)：11月12日発表。購買履歴SCI-CODEとSENSY GeoScopeを組み合わせ、未出店地域の顧客流入・売上・既存店への影響を予測する構想。実用化に向けた精度検証と共同ソリューション化を検討する段階で、検証済みの販売製品として扱わない。
- [Winning the Recommendation: How Multi-Location Brands Earn Visibility in AI-Powered Local Search](https://www.soci.ai/blog/winning-the-recommendation-how-multi-location-brands-earn-visibility-in-ai-powered-local-search/)：SOCiが米国2,998社・44業種のAI推薦を調査。上位5位に入る店舗割合の企業別平均は36.1%で、前回7.0%から上昇。Google Maps・店舗ページ・Yelpが主要な引用元。単一の質問形式による関連ツール提供企業の調査で、日本や全検索行動には一般化できない。
- [Geospatial maps in Snowflake CoWork (Preview)](https://docs.snowflake.com/en/release-notes/2026/other/2026-11-10-cowork-maps-preview)：11月10日、CoWorkの会話内で緯度経度・H3・GEOGRAPHY／GEOMETRYを対話型地図に表示するプレビューを発表。拡大縮小、保存・共有に対応し、クエリ連動地図は閲覧者の認証情報で再実行する。地図仕様はVega-Liteとは別。
- [Mapbox GL JS reduces GeoJSON memory usage by 2-3x for larger, more responsive web maps](https://www.mapbox.com/blog/mapbox-gl-js-reduces-geojson-memory-usage-by-2-3x-for-larger-more-responsive-web-maps)：11月13日発表。GL JS v3.31以降でGeoJSON処理のメモリ消費を改善し、コード変更なしで適用。提供元のベンチマークでは45〜75%減、160万地点のクラスタリングは642MBから82MBへ減少。geojson-vtとSuperclusterの型付き配列などの改良による。
- [【GeoAI】第26回：SDSC2026・金融×GeoAI](https://note.com/pacificspatial/n/n6b10454ea294)：SDSCの金融関連事例を紹介。Oxford Economicsの地域経済予測、ICEの気候リスク、Snowflakeの太陽光発電候補地選定シナリオ、JPMorganChaseのGIS基盤刷新を整理する。金融の判断に場所の違いを取り込む視点を示す。
