# 2026年9月11日の更新

## Cloud Native Geospatial

Cloud Native Geospatialを単一の規格ではなく、必要な部分だけを読むデータ形式、カタログ、配信方法、処理系の組み合わせとして整理した。STAC、COG、GeoParquet、Zarrの役割と、CNG Forumが標準化団体ではないことを明記した。

[Atlas](../atlas/concepts/cloud-native-geospatial.md) / [CNG Forum](https://cloudnativegeo.org/about/) / [解説記事](https://note.com/pacificspatial/n/nbaab8d8f3cab)

## 店舗画像によるPOIローカライゼーション

店舗の接写写真を広域の車載ストリートビュー画像と照合する非対称なPOI検索を整理した。GeoStoreベンチマークの構成、GLAMの全体検索と局所照合、実験結果、実務で確認すべき一般化とPOI更新の問題を記載した。

[Atlas](../atlas/methods/storefront-poi-localization.md) / [論文](https://arxiv.org/abs/2609.02012)
