- [Turning Geospatial Foundation Models into Decisions using CARTO Workflows](https://carto.com/blog/turning-geospatial-foundation-models-into-decisions-using-carto-workflows/)：2025年12月16日の記事を関連資料として確認。BigQuery上でPDFM・AlphaEarthの埋め込みを比較・分類・予測に使う例を紹介。年次変化には洪水以外の変化も含む。山火事例のリスク指標10％差は、予測精度10％向上を意味しない。 [Atlas](../atlas/methods/spatial-embeddings.md)

- [An Introduction to Python in Excel with ArcGIS for Excel](https://www.esri.com/arcgis-blog/products/arcgis-for-excel/announcements/an-introduction-to-python-in-excel-with-arcgis-for-excel)：10月6日公開。架空の調査30地点に半径10マイル圏の人口を付加し、Python in Excelでリスクと人口を3群に分類する。優先度は前処理と採点ルールにも依存する。ArcGIS API for PythonをExcel内で実行する例ではない。 [Atlas](../atlas/tools/arcgis-for-excel.md)

- [GeoSolutions at FOSS4G North America 2026 in Sacramento](https://www.geosolutionsgroup.com/news/geosolutions-at-foss4g-na-2026/)：10月7日公開。11月2〜4日のFOSS4G North Americaで、GeoServer・MapStore向けMCPによる管理、GeoServerの動向と性能比較、精密農業の4講演を予定。MCPは開発中の紹介であり正式提供の発表ではない。 [Atlas](../atlas/tools/geoserver.md)

- [True Data、プロショップ向けPOS・販売管理システムを展開するコスモネットを完全子会社化](https://prtimes.jp/main/html/rd/p/000000184.000039871.html)：10月7日、コスモネットの全株式取得・完全子会社化を決議。プロショップの購買データを標準化・統合し、地域・気象・住宅統計との需要予測を目指す。データ基盤と予測サービスは今後の計画で、完成済みの成果とは区別する。 [Atlas](../atlas/tools/location-intelligence-products-japan.md)

- [Why spatial work feels slow, and how AI in GIS is changing that](https://carto.com/blog/why-spatial-feels-slow/)：10月7日公開。GISの遅さをデータ移動、専門家への集中、条件変更時の作り直しから整理し、再利用できるWorkflowを提案。AIの初稿生成でレビュー負担が増える点を指摘する。CARTOによる自社製品を含む論考として読む。 [Atlas](../atlas/tools/carto-mcp-server.md)
