## Location AI

位置情報AIを、地理空間データ、API・MCP、Agent Skills、エージェント実行、結果のフィードバックという5層で整理した。Mapbox、xMap、TomTom Orbis、CARTOの公開情報を例に、接続機能とデータ品質・ガバナンスを分けて評価する観点も追加した。

[Atlas](../atlas/concepts/location-ai.md) / [Mapbox](https://docs.mapbox.com/help/getting-started/location-ai/) / [xMap](https://www.xmap.ai/ja)

## AIが扱いやすい地理空間開発環境

CARTOによるdeck.gl生成コードの実行検証とGoogle Maps Platform Agent Skillsをもとに、最新文書、推奨経路、Schema、状態読み戻し、認証・費用、実ブラウザ検証を一つの手法として整理した。

[Atlas](../atlas/methods/ai-ready-geospatial-development.md) / [deck.gl検証](https://carto.com/blog/making-deckgl-ai-ready/) / [Google Maps Platform Agent Skills](https://github.com/googlemaps/agent-skills)

## GISデータセットカタログ

GISデータをMCPへ公開する前段として、対応形式、CRS、Geometry、件数、bboxを検査し、物理パスではなくdataset IDとversionで参照する管理層を整理した。

[Atlas](../atlas/methods/gis-dataset-catalog-for-agents.md) / [実装記事](https://qiita.com/rino_yume/items/24ee23e203af14682e97)
