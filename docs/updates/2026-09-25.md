## 確認状況と重複

- 8件の本文を確認。Foursquareは公式の投稿表示用データで冒頭と日時を確認したが、長文部分は未取得である。画面・ランキング・Power user modeの詳細は確定情報として保存していない。
- Mapboxは9月18日に記録した公式発表の再紹介。新たな発売日として扱わず、重複ページを作成していない。新規に共有されたURL自体の登録重複はなかった。
- MapLibreは公式GitHub APIの公開日時とリリース本文を確認。小さな修正リリースのためAtlasの版一覧は増やしていない。
- CARTOは移行先を販売する立場の論考。Web AppBuilder Onlineの日程はEsriの延長告知とサポート資料で照合した。他製品の日程やライセンスの解釈は一括転載していない。
- イベント案内の追跡用クエリを除いたURLで本文を確認した。所感は標準の策定と実務での採用を分けて見る関心として要約し、添付内のAI回答は転載していない。
- ISO/TC 211のカタログで19178-1の発行済み版と改訂作業、TR 19182の開発中という区別を確認した。規格全文の適合要件や普及率は未検証である。
- Overtureの共通基盤論は筆者の提言として記録した。個別データの無条件な再配布許可と読み替えていない。
- Amap・HEREの機能や効果は企業発表に基づく。Qianyuの日本での利用条件、分析精度、NOAの車種別提供時期は確認していない。
