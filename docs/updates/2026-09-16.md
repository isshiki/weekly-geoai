# 2026年9月16日の更新

5件の出典を確認し、Atlasの4ページを新規作成、1ページを更新した。各出典の公開日は2026年9月15日、確認日は9月16日である。MapLibreの公開日はGitHubの表示日を記録している。

## 変更したAtlasページ

この一覧を選択して一括で開くと、Atlasページだけを確認できる。同じページは1回にまとめている。対応ブラウザーでは変更した文章をハイライトする。後日の改稿で文章が一致しなくなった場合はハイライトされない。
