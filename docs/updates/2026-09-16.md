# 2026年9月16日の更新

## MapLibre GL JS

MapLibre GL JS v6.10.0で、globeの空表示、面の三角形分割、地形に隠れたMarkerの判定が改善された。古いSafari、高ズームのhillshade、地形用テクスチャの解放なども修正された。

[Atlas](../atlas/tools/maplibre-gl-js.md) / [MapLibre / GitHub](https://github.com/maplibre/maplibre-gl-js/releases/tag/v6.10.0)

## ブラックフライデーの小売来訪分析

Foursquareが2025年の米国25市場について、ブラックフライデーの店舗来訪を直前4回の金曜日平均と比較した。総来訪量で選んだ市場を増加率で並べ、規模と当日の伸びを分けて捉える分析である。

[Atlas](../atlas/cases/black-friday-retail-visitation.md) / [Foursquare](https://foursquare.com/resources/blog/ad-tech/top-25-dmas-for-black-friday-shopping-matching-retail-strategy-to-market-surges/)

図版：追加なし。代表3市場の数値と比較期間は表と本文で把握できる。

## PASSER-MARKETING

技研トラステムがunerryと連携し、人数カウントとスマートフォン位置情報を組み合わせるPASSER-MARKETINGを開始した。来訪者属性・商圏・館内回遊・競合施設との併用関係を分析する。

[Atlas](../atlas/tools/passer-marketing.md) / [技研トラステム / PR TIMES](https://prtimes.jp/main/html/rd/p/000000013.000096417.html)

図版：追加なし。2種類のデータの役割と3つの分析メニューは本文と表で説明できる。

## 確認状況と重複

- 5件すべての本文を確認した。未確認の出典、同日内のURL重複、保存を省いたURLはいずれも0件である。
- MapLibreは既存ページへ追記した。GeoServerのMCPは開発方針、Mapboxの自然言語検索はPublic Previewとして扱う。
- GeoSolutionsの共有URLは `/blog/geosolutions-at-foss4g-2026/` だが、HTMLのcanonicalは `/news/geosolutions-at-foss4g-2026/` を指定している。後者も前者へリダイレクトして本文を返すことを確認し、日次ログにはcanonicalのURLを保存した。
